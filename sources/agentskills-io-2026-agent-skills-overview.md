## 한 줄 요약 (One-line Summary)

Agent Skills 오픈 표준의 공식 문서 사이트 홈. 포맷 정의와 progressive disclosure 3단계, 시작 가이드를 담고, 40여 개 AI 도구가 같은 포맷을 쓴다는 사실을 로고 쇼케이스로 보여준다. 사실상 cross-vendor 표준의 전시장인 셈이다.

## 1. 자료 정보 (Document Information)

- **출처**: agentskills.io/home (오픈 표준 문서 사이트). 저장소 [[agents/agentskills-agentskills]]의 문서가 사이트로 렌더된 형태.
- **성격**: 개념 소개 + Client Showcase + Quickstart·Specification 진입점.

## 2. 주요 기여 (Key Contributions)

1. **개념·규격의 소비자용 관문** — 저장소 README와 같은 정의를 사이트 형태로 제공한다(What/Why/How/Where).
2. **Client Showcase** — 40여 개 클라이언트를 한자리에 모아 채택 폭을 눈으로 보여준다. 이 자료만의 가치다.
3. **경쟁 벤더의 공존** — OpenAI Codex, Google Gemini CLI, Mistral Vibe, Microsoft(GitHub Copilot·VS Code), JetBrains Junie 등이 Anthropic 발 포맷을 함께 지원한다. 벤더 종속 없는 표준화 신호다.

## 3. 방법론 및 아키텍처 (Methodology and Architecture)

- **포맷·로딩 모델**은 저장소와 동일: `SKILL.md` 폴더 + discovery/activation/execution 3단계.
- **채택 생태계(사이트가 나열한 클라이언트, 발췌)**: Junie, Gemini CLI, Autohand, OpenCode, OpenHands, Mux, Cursor, Amp, Letta, Firebender, Goose, GitHub Copilot, VS Code, Claude Code, Claude, OpenAI Codex, Piebald, Factory, pi, Databricks Genie Code, Agentman, TRAE, Spring AI, Roo Code, Mistral Vibe, Command Code, Ona, VT Code, Qodo, Laravel Boost, Emdash, Snowflake Cortex Code, Kiro, Workshop, Google AI Edge Gallery, nanobot, fast-agent, bub, Tabnine, Vita, Superconductor, Deep Code.

## 4. 주요 결과와 벤치마크 (Key Results and Benchmarks)

벤치마크는 없다. 여기서 "지표"는 채택 규모다. 코딩 에이전트, IDE, 데이터 플랫폼, 헬스케어까지 도메인을 가로질러 40여 클라이언트가 지원한다.

## 5. 한계와 향후 과제 (Limitations and Future Work)

- **홍보성 나열**: 쇼케이스는 채택 사실만 보여줄 뿐, 각 클라이언트의 구현 충실도나 상호운용성까지 검증하지는 않는다.
- **스냅샷**: 생태계 목록은 빠르게 바뀐다. 이 source는 ingest 시점의 스냅샷일 뿐이다.
