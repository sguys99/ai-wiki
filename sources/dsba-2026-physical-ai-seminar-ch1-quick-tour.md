## 2. 주요 기여 (Key Contributions)

- **범위 설정**: Physical AI 가운데 손을 쓰는 로봇의 두뇌, 즉 robot manipulation을 위한 robot foundation model(VLA)에 초점을 둔다. 연구실 세미나 시리즈 전체가 VLA와 world model에 집중한다.
- **LLM 발전사와의 대응**: 로보틱스가 NLP의 경로(규칙 기반 → task별 딥러닝 → pre-training된 언어 모델)를 3~4년에 압축해 따라간다는 관점을 일관되게 쓴다. VLA 학습 레시피(VLM 초기화, cross-embodiment pre-training, task post-training, 실환경 RL)를 LLM의 pre-training, SFT, RLHF에 대응시킨다.
- **병목의 구조화**: 어려움을 데이터 격차, embodiment 이질성, 실시간성과 closed-loop와 비가역성, 일반화 격차의 네 가지로 정리하고 각각에 대표 수치를 붙인다.
- **기본기 정리**: VLA 입문자가 알아야 할 구성 요소(하드웨어 가격대, 시뮬레이터 비교, 데이터 수집 방식, 데이터셋, action 표현, action chunking, flow matching, dual-system 구조, 평가, 연구 규모별 GPU 자원)를 표로 정리한다.
- **진영 지형도**: 업계를 범용 로봇 두뇌, 풀스택 humanoid, 플랫폼과 생태계, world model 우선, 데이터 scaling의 다섯 진영으로 나누고, 핵심 질문 다섯 개(backbone, 데이터 원천, 새 task 학습 방법, 하드웨어, 모델 구조)에 대한 진영별 답을 대조한다.
- **연구 방향 지도**: Base VLA(VLM backbone + flow matching action expert)를 중심에 두고 3D, 촉각과 힘, memory, 비동기 실행, 추론, world model과 WAM의 여섯 확장을 "인간이 가진 능력을 하나씩 로봇에게 되돌려 주는 시도"로 묶는다.

## 3. 방법론 및 아키텍처 (Methodology and Architecture)

### 3.1 Physical AI의 정의와 등장 배경 (슬라이드 6~16)

**정의.** 발표자는 NVIDIA의 정의를 빌려 Physical AI를 "물리 세계를 지각하고 이해하고 추론해서, 그 안에서 직접 행동하는 AI"로 정의한다. 기존 AI와의 가장 큰 차이는 출력이 텍스트나 이미지가 아니라 물리적 행동(action)이라는 점이다. 학계에서는 Embodied AI, 산업과 행정에서는 Physical AI라는 용어를 쓰며 사실상 같은 대상을 가리키지만 단일 합의 정의는 없다. Physical AI의 범위는 manipulation, locomotion, humanoid(whole-body control), 자율주행, 드론, 산업 및 수술 로봇의 여섯 영역이고, 이 발표는 연구와 투자가 가장 집중된 manipulation을 다룬다.

**Digital AI와 Physical AI의 차이 (슬라이드 7).**

| 항목 | Digital AI (LLM, VLM) | Physical AI (VLA) |
|---|---|---|
| 출력 | 토큰, 묘사(describe) | 연속 action a(t : t+H), 행동(act) |
| 시간 | one-shot, 틀리면 재생성 | 50~200Hz closed-loop, 되돌릴 수 없음 |
| 세계 | 2D pixel과 text, 물리 법칙 무관 | 3D, 중력, 마찰, 충돌 |
| 감각 | vision, language | + proprioception, force, tactile |
| 오류 비용 | 거의 없음 (regenerate) | 물리적이고 영구적 |
| 데이터 | web-scale, 수집(scraped) | 직접 구매와 수집(bought) |

슬라이드의 결론은 "Physical AI = VLM의 지능 + 몸(body) + 실시간 closed-loop"이다. 발표자는 "챗봇은 틀리면 다시 생성하면 그만이지만 로봇이 컵을 떨어뜨리면 컵이 깨진다"는 예를 든다.

**역사 (슬라이드 11, 12).** 분야는 네 시기로 나뉜다.

| 시기 | 대표 사건 |
|---|---|
| 고전 로보틱스 (1960s~2000s) | Unimate (1961, GM 공장의 첫 산업용 로봇), Shakey (1966~72, 지각과 계획 로봇), 모델 기반 제어와 motion planning |
| Deep RL (2015~2019) | DARPA Robotics Challenge (2015, 우승 KAIST DRC-HUBO), end-to-end visuomotor policy (2016), OpenAI Dactyl 루빅스 큐브 (2019) |
| 데이터와 Transformer (2022~24) | SayCan, RT-1 (2022), Diffusion Policy, ACT (2023), RT-2의 'VLA' 용어 등장 (2023), Open X-Embodiment (2023), OpenVLA, π0 (2024) |
| Foundation model 경쟁 (2025~26) | GR00T N1, Gemini Robotics (2025), π0.5, V-JEPA 2, π*0.6 RL (2025), DreamZero 'WAM', π0.7 (2026), Gemini Robotics 2, GEN-1.5 (2026) |

분기점은 2023년 Google의 RT-2다. VLM이 그대로 로봇을 제어할 수 있음을 보였고 VLA라는 용어가 여기서 나왔다. 이후는 LLM과 VLM의 성공 공식을 로봇에 이식하는 시기다. 패러다임은 세 단계로 바뀌었다.

| 단계 | 구성 | 장점 | 단점 | NLP 대응 |
|---|---|---|---|---|
| 모듈형 파이프라인 | perception → state estimation → task, motion planning → control | 해석 가능, 안정적 | 비정형 환경과 새 물체에 취약, 모듈 간 오류 누적, 사람이 설계한 규칙에 의존 | rule, feature engineering |
| End-to-end learned policy | pixels → neural network → action | 지각과 행동의 통합 학습 | task 특화, 작업마다 새로 학습, 낮은 데이터 효율 | task-specific DL (RNN, CNN) |
| Robot foundation model (VLA) | 대규모 pre-training (web + 다중 로봇 데이터) → task post-training | web 지식 상속, 언어 지시, 다중 로봇과 task 일반화 지향 | 막대한 데이터와 연산, 신뢰성 | pre-training된 LM (BERT → GPT) |

발표자는 NLP 분야가 10년 가까이 걸린 과정을 로보틱스가 그 교훈을 바탕으로 3~4년 만에 따라가고 있다고 본다.

**지금 성장하는 이유 (슬라이드 13).**

- **VLM의 성숙**: web 지식이 로봇 제어로 전이된다는 것이 RT-2에서 확인됐고, OpenVLA와 π0가 open VLM 기반 VLA를 내놨다.
- **하드웨어 가격 급락**: humanoid Unitree R1 5,900달러, 로봇팔 SO-101 부품비 약 230달러, AgileX PiPER 1,999달러.
- **데이터 수집 인프라**: teleoperation 장비(ALOHA, GELLO, UMI), 공개 데이터셋(OXE, DROID, AgiBot World), GPU 병렬 시뮬레이터.
- **컴퓨팅과 자본**: 학습 GPU와 탑재형 edge compute(Jetson Thor), 투자 급증과 실매출 발생(Skild AI ARR 1억 달러).

**2026년 데모와 현실 (슬라이드 14, 15).** 2026년 데모로 Skild AI S1(사람 영상 하나로 10분짜리 작업), π0.7(학습하지 않은 조합의 task, language coaching), Gemini Robotics 2(humanoid whole-body control, 22-DoF 손), Figure Helix 2.5(처음 보는 가정 30곳에서 zero-shot), GEN-1.5(3~12초 시연만으로 in-context 학습), AgiBot(humanoid의 셔츠 개기)을 든다. 발표자는 "1~2년 전 불가능했던 장면이 매달 공개되지만 데모와 실제 성능은 별개"라고 덧붙인다.

| 되는 것 | 아직 안 되는 것 |
|---|---|
| 정형 환경의 short-horizon 작업 (pick-and-place, 정리, 빨래 개기) | 처음 보는 환경, 물체, 지시에 대한 일반화 |
| task 데이터로 fine-tuning한 특정 작업 | 수십 분 이상의 long-horizon 작업 |
| 공장과 물류의 반복 작업 파일럿 | 산업 수준 신뢰도 (99.9%) |
| | 정교한 dexterous 작업과 접촉 작업 |

데모의 이면으로 Tesla Optimus 시연(2024.10) 다수가 원격 조종이었다는 점, 1X NEO(2만 달러)가 'Expert Mode'에서 원격 operator가 대신 작업한다는 점을 든다. 성공률 95%도 하루 500번 작업하면 25번 실패한다는 뜻이다. 발표자는 이 분야의 교수와 기업 연구원들에게서 "아직 task가 상당히 단순하고, training time에서 겨우 잘하는 수준이며 실제로 써 보면 test time에서 잘 작동하지 않는다"는 이야기를 많이 듣는다고 전한다.

**여러 분야의 문제의식 (슬라이드 16).** Physical AI에는 아직 master solution이 없고 여러 배경의 질문이 모인다. LLM과 VLM(언어 지시와 계획을 어떻게 행동으로), 3D vision(2D 기반 encoder로 3D 정밀 조작이 가능한가), video generation(영상 생성 모델이 시뮬레이터가 될 수 있는가), 센서와 촉각, cross-embodiment, 강화학습(시연 데이터를 넘어 스스로 개선), 로보틱스와 제어(수 Hz의 거대 모델로 수백 Hz 제어), 데이터와 시스템(수집, 정제, 평가 파이프라인, 경량화), memory와 continual learning, 멀티로봇과 멀티에이전트 협업이다. 발표자는 정해진 해법과 글로벌 컨센서스가 없어 학계 연구자에게는 할 일이 많다고 본다.

### 3.2 어려운 이유와 네 가지 병목 (슬라이드 18~23)

**Moravec's Paradox (슬라이드 18).** "컴퓨터에게 어른 수준의 지능 검사를 풀게 하는 것은 쉽지만, 지각과 이동에서 한 살 아이의 능력을 주는 것은 어렵거나 불가능하다"(Hans Moravec, Mind Children, 1988). AI에게 쉬운 것은 수학 올림피아드 금메달 수준 추론, 체스와 바둑, 코드 작성, 시험이고, 어려운 것은 빨래 개기, 식기 정리, 처음 보는 컵 집기, 한 살 아이의 감각운동이다. Physical Intelligence는 그 원인을 데이터 부족으로 해석한다. 신체 기술은 인터넷에 없고, 실제 세계에서 동작하는 데이터는 대규모로 모으기도 어렵다. PI의 'Robot Olympics'에서 fine-tuning된 π0.5의 평균 성공률은 52%였고, 로봇 pre-training이 없는 VLM은 0%였다. 인간에게 쉬운 일은 수억 년 진화로 최적화된 감각운동 능력이라 명시적 지식으로 표현할 수 없고 텍스트로 학습할 수 없다.

**병목 1 데이터 격차 (슬라이드 19).**

| 데이터 | 규모 (시간, 로그 스케일 그래프) |
|---|---|
| 인터넷 영상 (V-JEPA 2) | 100만 시간 이상 |
| 착용형 장치 (GEN-1) | 50만 시간 이상 |
| 로봇 teleoperation (π0) | 약 1만 시간 |
| 로봇 teleoperation (DROID) | 350시간 |

web image-text는 58억 5천만 쌍(LAION-5B), web text는 15조 토큰 이상(Llama 3)이며, 사람이 읽는 데 약 10만 년이 걸린다(Goldberg의 "100,000-year data gap"). 로봇 데이터는 "bought, not scraped"라서 작업 1시간이 곧 데이터 1시간이고 operator 인건비, 장비, 현장 비용이 든다. 우회로는 사람 착용 장치 데이터(GEN-1 50만 시간 이상)다. 데이터 질의 문제도 있다. 영상에는 3D, 힘, 촉각 정보가 없고, 성공 시연 위주라 실패와 회복 데이터가 부족하다. 슬라이드는 이를 "LLM의 성공 공식(scraping + scaling)이 그대로 통하지 않는 첫 번째 이유"로 요약한다.

**병목 2 embodiment 이질성 (슬라이드 20).** 로봇마다 관절 수(DoF), 그리퍼와 손의 구분, 카메라 위치와 개수, control frequency, action 정의(joint 또는 end-effector)가 다르다. LLM은 하나의 vocabulary를 공유하지만 로봇 action에는 공통 '언어'가 없어 데이터 통합 학습이 어렵고 새 로봇마다 추가 수집과 학습이 필요하다. 대응은 다음과 같다.

- embodiment별 입출력 모듈과 공유 trunk (HPT, CrossFormer). CrossFormer는 팔, 바퀴, 드론, 4족 로봇을 하나의 Transformer로 다룬다.
- 데이터 원천별 soft prompt (X-VLA), action 차원 padding (π0).
- 사람 손에서 로봇으로의 retargeting.

Open X-Embodiment는 22종 로봇, 21개 기관, 100만 개 이상의 trajectory를 모았다.

**병목 3 실시간성, closed-loop, 비가역성 (슬라이드 21).** VLM(3B 이상) 추론은 한 번에 약 100~300ms라 수 Hz로 동작하지만 로봇 제어는 50~200Hz로 명령을 받아야 한다.

| 항목 | 내용 |
|---|---|
| 실시간 제어 | 제어 50~200Hz, 전신 균형 제어 1kHz, VLM 추론은 수 Hz |
| closed-loop | 내 행동이 다음 입력을 바꾸고, 작은 오차가 누적되어 학습 분포를 벗어난다 (compounding error) |
| 온디바이스 | 로봇 탑재 연산과 전력 한계 (Jetson Thor 130W), 경량화와 가속 필요 |
| 비가역성과 안전 | 깨진 컵은 regenerate 불가, 사람 근처 동작의 안전 보장 |

발표자는 정답을 한 번 맞히는 문제가 아니라 정해진 시간 안에 계속 행동해야 하는 문제라 더 어렵다고 설명한다.

**병목 4 일반화 격차 (슬라이드 22).** 현장의 공통 평가는 "아직 단순한 task 위주이고, 학습 분포 안에서도 겨우 잘하는 수준이며, 실제 배치 시 성능이 크게 하락한다"는 것이다.

| 벤치마크 | 수치 | 조건 |
|---|---|---|
| LIBERO-PRO | 90% 이상 → 0% | 물체 위치, 지시문 변경 시 |
| LIBERO-Plus | 95% → 30% 미만 | 카메라 시점, 초기 자세 변경 시 |
| LIBERO-Gen (π0.5) | 21.2% | 학습한 기술의 새 조합 (Task-CG) |
| BEHAVIOR 2025 1위 | 0.26 / 1.0 | 가장 long-horizon한 50개 task |

LIBERO-PRO에서는 지시문을 무의미한 토큰으로 바꿔도 로봇이 같은 행동을 한다. 발표자는 이를 언어를 이해했다기보다 action trajectory 자체를 외웠다는 뜻으로 해석한다. LIBERO-Plus에서는 언어 지시를 대부분 무시한다. 원인 가설은 물체와 위치의 결합 학습(spatial overfitting), 취약한 시각 표현, 데이터 다양성 부족이다. 결론은 "높은 벤치마크 점수가 일반화를 뜻하지 않으며, 암기와 이해를 구분하는 평가가 중요한 과제"라는 것이다.

**Scaling 논쟁 (슬라이드 23).**

| scaling 진영 (더 많고 더 다양한 데이터) | 구조 진영 (scaling만으로는 부족) |
|---|---|
| Data Scaling Laws (ICLR 2025): 일반화 성능이 환경과 물체 수에 대해 power law | Compositional generalization 실패 (Task-CG 21%) |
| GEN-0 (Generalist): 27만 시간, 7B 이상에서 지속적 scaling (1B는 정체) | Brooks: "today's humanoid robots will not learn how to be dexterous", 영상에는 촉각과 힘이 없다 |
| EgoScale (NVIDIA): human video 2만 시간, 규모와 loss가 log-linear 관계이며 실제 로봇 성능을 예측 | World model 진영 (LeCun, AMI Labs): 다음 상태 예측으로 물리 이해 |
| | 3D와 촉각 같은 구조적 prior 도입 (05장) |

공통 쟁점은 데이터의 '양'보다 '다양성'이며, 어떤 데이터(teleoperation, human video, 시뮬레이션)가 scalable한지다. Levine은 "Sporks of AGI"(2025)에서 시뮬레이션과 human video 같은 대체 데이터는 결국 타협이라고 반론했다. 발표자는 LLM에서 본 emergent ability 같은 '와우 모멘트'가 아직 뚜렷하지 않고, 데이터의 양보다 다양성이 중요하다는 정도가 알려져 있다고 정리한다.

### 3.3 기본 구성 요소 (슬라이드 25~40)

**기본 용어와 파이프라인 (슬라이드 25).** 기본 루프는 observation(카메라 이미지, proprioception, 언어 지시) → policy π(a | o, ℓ) → action(action chunk, 예를 들어 1초 분량) → 로봇과 환경(실제 물리 세계) → 다시 observation으로 이어지며 초당 50~200회 반복된다.

| 용어 | 슬라이드 설명 |
|---|---|
| policy | observation과 지시를 받아 action을 출력하는 모델 (VLA 등 학습된 모델) |
| proprioception | 로봇 자신의 상태 (관절 각도, 그리퍼, 손끝 위치) |
| action space | joint position 또는 end-effector pose (IK 필요) |
| DoF | 독립 관절 수 (6-DoF 팔 + 그리퍼, 손은 12~22) |
| teleoperation | 사람이 원격 조종해 시연 데이터 수집 |
| embodiment | 특정 로봇의 몸 (cross-embodiment는 여러 몸) |
| rollout과 success rate | 1회 실행, task당 10~100회 시행의 성공 비율 |
| control Hz와 sim2real | 초당 명령 횟수, 시뮬레이션 policy를 실제 로봇으로 옮기는 문제 |

**하드웨어 (슬라이드 26).** 표준 세팅은 로봇팔(6~7 DoF), 평행 그리퍼, 카메라 2~3대(wrist와 3인칭), teleoperation 장치다. π0는 base 카메라 1대와 wrist 2대, DROID는 3인칭 stereo 2대와 wrist 1대를 쓴다. 센서는 RGB(-D) 카메라, 힘과 토크 센서, 촉각 센서(GelSight, DIGIT)다. 학습은 서버 GPU에서, 추론은 로봇 옆 workstation이나 Jetson에서 한다. 발표자는 촉각 센서가 생각보다 매우 비싸서 갖추기 어렵다고 말한다.

| 형태 | 예시 | 가격대 (USD) | 용도 |
|---|---|---|---|
| 저가 단일 팔 | SO-101 (LeRobot), Koch | 200~500 | 교육, 빠른 프로토타입 |
| 연구용 단일 팔 | AgileX PiPER / xArm / Franka FR3 / UR5e | 2,000 / 8,000~12,000 / 25,000~30,000 / 35,000 | 표준 연구 |
| 양팔 (bimanual) | ALOHA, Trossen AI Stationary | 약 20,000~24,000 | 세밀 작업, 빨래, 조립 |
| 모바일 매니퓰레이터 | Mobile ALOHA, Galaxea R1 Lite, Stretch | 30,000~70,000 | 가정, 이동 작업 |
| humanoid | Unitree G1 (EDU), H2 | 14,000부터 (EDU 44,000 이상), 41,000부터 | whole-body control 연구 |
| dexterous hand | LEAP / Allegro / Inspire | 2,000~21,000 | 손 조작 |

**시뮬레이터 (슬라이드 27, 28).** 시뮬레이션의 목적은 실제 로봇보다 빠르고 싸고 안전하게 대규모 병렬 학습(RL), 시연 데이터 생성, 재현 가능한 평가, 합성 데이터를 얻는 것이다.

| 프로그램 | 개발과 라이선스 | 강점 | 필요 사양 | 주 용도와 대표 벤치마크 |
|---|---|---|---|---|
| Isaac Sim / Isaac Lab | NVIDIA, 오픈소스 (일부 구성요소 비공개) | GPU 병렬 물리 (PhysX) + RTX 렌더링, 센서, VR teleoperation, 합성 데이터 | RTX GPU 16GB 이상, RAM 32~64GB, A100과 H100 미지원 (RT core 부재) | 대규모 RL (보행, 손 조작), GR00T 데이터 생성, BEHAVIOR |
| MuJoCo | Google DeepMind (+NVIDIA), Apache-2.0 | 정확하고 가벼운 접촉 물리, JAX와 Warp로 GPU 병렬 확장 | CPU만으로 가능 (노트북 가능), GPU 병렬은 NVIDIA GPU | VLA 벤치마크의 기반 (robosuite → LIBERO, RoboCasa) |
| ManiSkill3 | UCSD Hao Su lab, Apache-2.0 | GPU 병렬 시뮬레이션과 렌더링, 30,000 FPS 이상 (RTX 4090) | NVIDIA GPU + Vulkan (Linux), A100은 Vulkan 설정 추가 | manipulation RL, IL, SimplerEnv, RoboTwin 2.0 |
| Genesis | Genesis AI와 커뮤니티, Apache-2.0 | 다중 물리 (강체, 천, 유체, MPM), 속도 주장 (4,300만 FPS)은 논쟁 중 | CUDA, ROCm, Metal, CPU로 하드웨어 선택 폭이 넓음 | 변형 물체, 다중 물리 연구. GitHub star는 최다지만 벤치마크 채택은 적음 |
| Newton (차세대 엔진) | NVIDIA, DeepMind, Disney, Apache-2.0 | Warp 기반 GPU 물리, MuJoCo Warp 통합, 1.0 출시 (2026.03) | Turing 이상 NVIDIA GPU (compute capability 7.5+) | Isaac Lab 3.0 기본 backend, Isaac Sim 없이 학습 (kit-less) |

그 밖에 Gazebo(ROS 생태계), PyBullet(교육, legacy), Drake(TRI, 모델 기반 제어)가 있다. 발표자의 연구실은 Isaac Sim을 A6000에서, MuJoCo, ManiSkill3, Newton을 A100과 H100에서 쓴다. 음성에서는 Isaac이 렌더링에 RT core를 요구해 A100이나 H100에서 동작하지 않으므로 RTX GPU 중에서도 40 시리즈 이상이 필요하다고 설명한다.

시뮬레이션으로 가능한 것은 네 가지다.

1. **대규모 병렬 RL**: 수천 개 환경을 병렬로 구동해 ANYmal 평지 보행을 GPU 1장으로 4분 만에 학습한다. Dactyl은 시뮬레이션에서만 학습한 손으로 루빅스 큐브를 풀었다 (domain randomization).
2. **시연 데이터 생성과 증강**: MimicGen은 사람 시연 약 200개로 5만 개 이상을 자동 생성한다. GR00T N1은 합성 trajectory 78만 개를 11시간에 생성했고 실제 데이터만 쓸 때보다 성능이 40% 높았다.
3. **재현 가능한 policy 평가**: LIBERO 130 tasks, RoboCasa365 365 tasks, BEHAVIOR 50 tasks. SimplerEnv는 sim 평가와 실제 로봇 성능의 상관이 r = 0.92다.
4. **합성 데이터와 digital twin**: domain randomization(조명, 배경, 질감)과 Cosmos Transfer로 사실적 영상을 만들고, Real2Sim은 Gaussian Splatting 기반 digital twin 안에서 VR teleoperation으로 데이터를 모은다.

sim2real gap은 시뮬레이션에서 학습한 policy가 실제 로봇에서 성능이 떨어지는 현상이다. 원인은 접촉과 마찰 모델의 근사, 변형 물체, 렌더링 영상과 실제 카메라 영상의 차이, 센서 노이즈와 지연, actuator 동역학이다. 대응은 domain randomization, system identification, Real2Sim digital twin, sim과 real의 co-training이다. 현황은 locomotion에서는 sim2real이 정착했지만 contact-rich manipulation에서는 여전히 gap이 커서 실제 로봇 데이터를 병행한다. 그래서 논문에는 실제 로봇 실험 결과를 웬만하면 포함해야 한다.

**데이터 수집 (슬라이드 29, 30).**

**VLA 구조 (슬라이드 32, 33).** VLA는 pre-training된 VLM에 action 생성 모듈을 더한 모델이다. 입력은 이미지, 언어 지시, 로봇 상태이고 출력은 action chunk다. VLM backbone은 web-scale image-text 지식(물체 인식, 언어 이해, 상식)을 상속하고, action expert는 VLM 표현을 받아 연속 action을 생성한다 (flow matching 또는 diffusion).

| 모델 | Backbone | Action 생성 | 크기 |
|---|---|---|---|
| OpenVLA (2024) | Llama 2 7B + DINOv2, SigLIP | 이산 토큰 | 7B |
| π0 (2024) | PaliGemma 3B | flow matching expert (300M) | 3.3B |
| SmolVLA (2025) | SmolVLM2 | flow matching expert | 0.45B |
| GR00T N1.7 (2026) | Cosmos-Reason2-2B (Qwen3-VL 계열) | flow matching DiT | 약 3B |
| π0.7 (2026) | Gemma 3 4B | action expert (860M) | 약 5B |

"VLM이 보고 이해하고 action expert가 움직이는" 구조이며 2~5B 규모가 현재 표준이다. 발표자는 on-device 실시간 추론 때문에 최근 LLM보다 훨씬 작다고 설명한다.

슬라이드 33은 입력에서 action까지의 데이터 흐름을 단계별로 그린다.

| 단계 | 구성 |
|---|---|
| 입력 | 카메라 이미지 o_t (카메라 N대 × 224 × 224 × 3, 외부 고정 + 손목), 언어 지시 ℓ ("put the bottle in box 1"), 로봇 상태 s_t (관절 각도, 손끝 위치, 그리퍼, 7~14차원) |
| Encoder | Vision Encoder (ViT 또는 ResNet, pre-training됨) → 이미지 토큰, Tokenizer + Embedding → 텍스트 토큰, State Encoder (MLP) → 1 state token |
| Backbone | Transformer 또는 VLM이 모든 토큰을 함께 처리해 상황 요약 context c를 만든다 |
| Action head (diffusion 또는 flow) | 노이즈 예측 네트워크 (Transformer)가 action token과 context c 사이 cross-attention을 수행한다. Action Encoder (MLP, step k 포함)와 Action Decoder (MLP → H × D_a)가 노이즈 섞인 action A^k에서 ε 또는 v를 예측하고 k = K부터 1까지 반복한다 |
| 출력 | action chunk A_t = A^0 (H × D_a), 예를 들어 16스텝 × 7차원 (위치와 방향 변화량 + 그리퍼 개폐) → 로봇 제어기 (관절, 모터 제어) |

학습은 시연 (o, ℓ, s, a_{t:t+H})의 a에 노이즈를 섞고 ε를 예측하는 MSE로 한다. 추론은 무작위 노이즈에서 시작해 K번 노이즈를 제거한 뒤 묶음의 앞부분만 실행하고 다시 예측한다. 이산 토큰 방식(RT-2, OpenVLA)은 action head 없이 LLM이 action을 토큰으로 직접 출력하고, 토큰을 차원별 256구간 값으로 되돌린다. 회귀 방식은 MLP 하나로 바로 출력한다. 음성에서는 카메라 이미지, 언어 지시, proprioception이 각각 토큰이 되어 VLM에 들어가고, VLM이 만든 representation을 condition으로 action expert가 diffusion이나 flow matching으로 action 시퀀스를 생성한다고 요약한다.

**action 표현 (슬라이드 34, 35).** 사람은 손을 공간 좌표로 생각하지 않지만 로봇에게는 명시해야 한다.

- **관절 공간 (joint space)**: 각 관절의 각도를 직접 지정한다 (관절 7개 → 7차원). 구조가 다른 로봇에는 쓸 수 없고 관절 각도 움직임 자체를 학습하기도 어렵다.
- **손끝 공간 (end-effector space)**: 손끝의 위치 (x, y, z), 방향, 그리퍼 개폐로 표현하며 대부분의 policy가 채택한다. 절대 좌표인지 현재 위치 대비 변화량(delta)인지는 데이터셋마다 다르므로 반드시 확인한다. 방향은 Euler 각, quaternion, 6D 표현(학습에 유리) 등으로 나타낸다.
- **정규화**: 차원별로 값의 범위를 맞춰 로봇과 데이터셋마다 다른 단위와 크기를 보정한다.
- **행동 단위의 변화**: 평면 위 집기와 놓기 → 3D 공간의 핵심 자세 → 연속 trajectory와 action 묶음.

제어는 계층으로 나뉜다. policy π_θ가 5~50Hz로 손끝 목표 자세를 내면, 로봇 제어기가 100Hz~1kHz로 목표 자세를 관절 각도와 모터 힘으로 바꾸고, 모터가 로봇을 움직인 뒤 observation(카메라, 로봇 상태)이 피드백된다. 슬라이드의 결론은 "policy는 손끝의 목표만 내고(초당 약 10회), 관절과 모터를 움직이는 일은 로봇 제어기가 담당한다(초당 약 1,000회)"이며, VLA 분야에서 low-level policy라 부르는 것도 실제로는 모터 제어기보다 한 층 위에 있다.

action 출력 형태는 이산 토큰에서 연속 생성으로 옮겨 왔다.

| 방식 | 대표 | 장점 | 단점 |
|---|---|---|---|
| 이산 토큰 (autoregressive) | RT-1, RT-2, OpenVLA: 차원별 256구간으로 이산화해 텍스트 토큰처럼 생성. FAST (2025): DCT + BPE 압축 (700 → 53 토큰), 학습 최대 5배 가속 | VLM 구조를 그대로 활용 | 느린 순차 생성, 고주파 정밀 동작이 어려움 |
| 연속 생성 (regression, diffusion, flow) | Regression: OpenVLA-OFT (병렬 decoding, LIBERO 97.1%). Diffusion과 flow matching: Diffusion Policy, π0, GR00T | 다봉 분포 표현, 부드러운 trajectory, 고주파 제어 (50Hz)에 적합 | |

현재의 수렴점은 backbone은 토큰으로 학습하고 실제 action은 flow matching으로 생성하는 방식이다 (knowledge insulation, π0.5~π0.7). 슬라이드는 이를 "언어처럼 쓰는 action과 그림처럼 생성하는 action이 하이브리드로 수렴"한다고 표현한다.

**action chunking (슬라이드 36).** 한 번에 1스텝이 아니라 미래 H스텝의 action 묶음(chunk)을 예측한다. ACT는 50Hz에서 chunk 90, π0는 50Hz에서 chunk 50(약 1초)을 쓴다.

- **compounding error 감소**: 결정 횟수가 1/H로 줄어 오차가 덜 쌓인다.
- **시간적 일관성**: 부드럽고 일관된 동작.
- **추론 지연 극복**: 실행 중에 다음 chunk를 준비한다.
- **한계**: 긴 chunk를 실행하는 동안 환경 변화에 둔감하다. 대응은 receding horizon, temporal ensembling, real-time chunking(05장)이다. chunk가 길수록 과거 기억은 늘고 최신 observation 반영은 줄어드는 trade-off가 있다 (BID, 2025).

슬라이드 그림은 t = 0에서 16스텝(T_p = 16)을 예측하고 앞 8스텝(T_a = 8)만 실행한 뒤 t = 8에서 다시 예측하는 모습이다. 음성은 뒤쪽 스텝을 버릴 것인데도 더 많이 만드는 이유를 두 가지로 설명한다. 뒤쪽까지 고려해야 더 부드럽고 성공적인 동작이 나오고, 통신 오류나 추론 지연으로 다음 chunk를 못 만들어도 이전 chunk를 계속 쓰면 되기 때문이다. 한 스텝은 end-effector 방식에서 보통 7개 스칼라이므로 16스텝 예측이면 16 × 7개 값을 출력한다. 음성은 7개를 xyz 위치, xyz 방향, 그리퍼 개폐 정도로 설명하며, 슬라이드 33은 "위치와 방향 변화량 + 그리퍼 개폐"로 적는다.

**Diffusion Policy와 flow matching (슬라이드 37).**

| 항목 | Diffusion Policy | Flow Matching |
|---|---|---|
| 아이디어 | 이미지 생성의 diffusion을 action trajectory 생성에 적용 | 직선 경로 위의 속도장(vector field) 학습 |
| 과정 | noise → observation 조건 점진적 denoising → action chunk | 추론 시 noise에서 적분 (π0: 10 step) |
| 강점 | 여러 정답(다봉 분포)을 평균내지 않고 표현, regression의 '평균의 함정' 해결, 12개 task 평균 +46.9% | diffusion 대비 단순하고 빠름 |
| 채택 | | π0, GR00T, SmolVLA 등 최신 VLA의 표준 action head |

flow matching의 학습 목적식은 x_t = (1 − t) a + t ε, u_t = ε − a, L_fm = E[‖v_θ(o, x_t, t) − u_t‖²]이다. 음성은 완전한 노이즈 ε와 데이터 a를 잇는 선분 위의 점에서 노이즈에서 데이터로 가는 속도 벡터를 맞히도록 학습하며, 단위 시간을 1로 두면 속도가 ε − a가 된다고 설명한다. diffusion이 노이즈를 직접 맞히는 것에 비해 인스턴스마다 하나의 속도만 맞히면 되므로 학습이 더 안정적이고 필요한 스텝이 훨씬 적다. 그래서 이미지와 영상 생성 모델, VLA와 world model 분야에서 대부분 flow matching을 쓴다. 슬라이드 그림은 Diffusion Policy, LSTM-GMM, BET, IBC를 비교해 다봉 분포에서 Diffusion Policy만 두 경로 중 하나를 일관되게 선택함을 보인다.

**System 2와 System 1 (슬라이드 38).** Kahneman의 구분을 빌려 System 2는 느리고 숙고하며 논리적인 사고(처음 보는 가구 조립), System 1은 빠르고 자동적이며 직관적인 반응(컵 잡기)이다. 반복 연습으로 숙고가 직관이 된다(S2 → S1). 큰 VLM이 느리게 작업을 이해하고 계획하는 역할(System 2)을, action chunk를 생성하는 모델이 그 계획에 따라 실제 action을 내는 역할(System 1)을 맡는다. 발표자는 이를 두뇌와 말초신경에 비유한다.

| 모델 | System 2 | System 1 |
|---|---|---|
| Figure Helix (2025) | 7B VLM, 7~9Hz | 80M policy, 200Hz |
| Figure Helix 02 (2026) | 동일 | + S0 균형 제어, 1kHz |
| NVIDIA GR00T N1 (2025) | VLM, 약 10Hz | DiT, 약 120Hz |
| PI Hi Robot (2025) | VLM: subtask 지시 | π0 계열 VLA |
| Gemini Robotics 1.5 | ER 1.5: 계획과 추적 | VLA: 실행 |

현재 robot stack은 System 1 중심이며, 결과를 예측하고 평가하고 수정하는 진정한 System 2는 초기 단계다. 발표자는 world model을 System 2의 발전 방향으로 본다.

**평가 (슬라이드 39).**

| 시뮬레이션 벤치마크 | 실제 환경 평가 |
|---|---|
| 재현 가능하고 저비용이지만 sim-real gap이 있다 | 최종 기준이지만 느리고 비싸며 재현이 어렵다 |
| LIBERO (130 tasks): 사실상 포화 (π0.5 96.9%, OFT 97.1%) | RoboArena: 여러 기관의 double-blind pairwise 비교 (Chatbot Arena 방식) |

| CALVIN, RoboCasa, RoboTwin 2.0, BEHAVIOR | world model 기반 평가 (03장) |

발표자는 LIBERO가 약 97%로 포화됐지만 시나리오를 조금 비틀면 성공률이 꽤 내려간다고 말한다. 결론은 포화된 벤치마크와 비싼 실환경 사이에서 신뢰할 수 있는 평가 자체가 미해결 문제라는 것이다.

**연구 규모별 필요 자원 (슬라이드 40).**

| 연구 주제 | 대표 예시 | GPU | 로봇과 데이터 | 규모 참고 |
|---|---|---|---|---|
| 소형 policy 학습 | ACT, Diffusion Policy (task별 policy) | 소비자 GPU 1장 (12~24GB) | 로봇 1대 + teleoperation 장치, task당 시연 수십~수백 개 | 학습 수 시간 |

### 3.4 World model (슬라이드 42~47)

**필요성 (슬라이드 42).** 현재 VLA는 observation을 보고 바로 행동하는 반응형(reactive)이라 "이렇게 하면 어떻게 될까"를 예측하는 과정이 없다. world model은 o와 후보 action을 받아 결과를 예측하고 평가한 뒤 action을 선택하게 한다 (p(s_{t+1} | s_t, a_t)). 인간도 머그컵을 잡기 전에 무게와 그립을 미리 예측한다(forward model). 데이터 관점에서는 action 라벨이 없는 대량의 영상으로 물리 동역학을 학습할 수 있어 데이터 격차를 완화한다.

LeCun은 두 가지 모드를 구분한다. Mode-1은 지각에서 즉각 행동으로 가는 경로로 현재 VLA(System 1)에 해당하고, Mode-2는 world model로 결과를 시뮬레이션하며 최적 행동을 탐색하는 경로로 System 2에 해당한다. Mode-2의 결과로 Mode-1을 학습시켜 계획을 반응 policy로 옮긴다. 슬라이드의 결론은 "World model = 로봇에게 '상상력'을 부여하는 System 2의 핵심 부품"이다.

**계보와 분류 (슬라이드 43).** 기원은 World Models(Ha와 Schmidhuber, 2018)다. VAE로 observation을 압축하고(V), RNN으로 미래를 예측하며(M), controller(C)가 '상상 속에서' policy를 학습한다. 이후 Dreamer 계열(DreamerV3, Nature 2025)과 DayDreamer(2022, 실제 로봇에서의 Dreamer)로 이어졌다. 핵심 논쟁은 pixel 예측(생성형)과 latent 예측(JEPA)이다.

| 유형 | 예측 대상 | 대표 연구 | 특징 |
|---|---|---|---|
| Latent dynamics (model-based RL) | 압축된 latent 상태 | Dreamer v1~v3, DayDreamer | 상상 속 RL, task 특화 |
| Pixel / Video 생성형 (world foundation model) | 미래 영상 프레임 | UniSim, Genie 3, NVIDIA Cosmos, 1X WM | web 영상의 물리 prior, 사람이 확인 가능, 고비용 |
| Latent 예측형 (JEPA) | 미래의 표현 | V-JEPA 2, DINO-WM | 불필요한 디테일 무시, 효율적 계획 |
| 3D 물리 세계 생성 | 시뮬레이션 가능한 3D 환경 | World Labs Marble, Genesis | 시뮬레이터용 환경 생성 |

음성은 latent 예측 방식을 인간의 상상 방식에서 따온 것으로 설명한다. 사람이 머릿속으로 상상할 때 배경과 가장자리까지 매 프레임 RGB 값을 생성하지 않고 집중하는 대상 위주로 약간 추상적인 시각적 상상을 한다는 것이다. 이 방향은 LeCun이 주도하지만 발표자는 아직 상대적으로 더 잘 되고 있다고 보기는 어렵다고 평가한다.

**대표 연구 (슬라이드 44).**

| 연구 | 내용 |
|---|---|
| Genie 3 (Google DeepMind, 2025.08) | 텍스트로 생성한 세계와 실시간 상호작용 (720p, 24fps), 수 분간 일관성 유지, Project Genie 공개 (2026.01) |
| NVIDIA Cosmos (2025.01 → Cosmos 3) | Physical AI용 open world foundation model, 합성 데이터와 policy 학습 플랫폼, Cosmos 3는 reasoning + 영상과 action 생성 (4B~64B) |
| V-JEPA 2 (Meta, 2025.06) | 영상 100만 시간 이상으로 action 없이 pre-training, DROID 62시간 미만으로 action-conditioning, 처음 보는 실험실에서 zero-shot 집기와 놓기 |
| 1X World Model (2024 → 2026.01) | humanoid policy 평가용 시뮬레이터 (2024), 14B 영상 모델 + IDM으로 policy 자체로 사용 (2026) |

발표자는 Cosmos Predict 2.5 논문에서 H100 4,096장을 학습에 썼다는 데 충격을 받았다고 말한다. 그러면서도 큰 자원으로 학습한 world model도 아직은 이전 프레임을 받아 미래 프레임을 출력하는 video prediction 모델에 지나지 않는 경우가 많다고 본다. Genie 3 소개 영상에서는 텍스트 프롬프트로 세계를 만들고 WASD 키로 조작한다. 일반 게임처럼 3D 모델을 렌더링하는 것이 아니라 이동에 맞춰 그럴듯한 프레임을 실시간으로 생성하므로, 선택한 action에 따른 환경 변화를 예측하는 것에 가깝다.

**활용 (슬라이드 46).**

| 활용 | 방법 | 예시 |
|---|---|---|
| ① 데이터 생성 | 새 행동 영상 생성 → IDM으로 action 라벨링 | DreamGen: 단일 task 데이터로 22개 새 행동 |
| ② policy 평가 | world model 속 rollout으로 policy 순위 예측 | GDM Veo 기반 평가 (실평가로 검증) |
| ③ 계획 (MPC) | 후보 action을 상상한 뒤 목표에 가장 가까운 것 선택 | V-JEPA 2-AC, DINO-WM |
| ④ 상상 속 RL | 안전, 무한 리셋, 병렬 rollout | WMPO: 성공률 53% → 70% |
| ⑤ policy backbone | world model 자체를 policy로 사용 | World Action Model (05장) |

Ctrl-World 그림은 실제 rollout과 world model의 상상이 거의 같은 모습을 보여, 실제 로봇 없이 policy를 평가할 가능성을 보여준다. WMPO는 world model 안에서 VLA를 RL로 학습한다. 다만 world model은 여전히 실제 로봇 실험만큼 신뢰하기 어렵다.

**남은 과제 (슬라이드 47).**

- **물리적 환각**: 그럴듯하지만 물리 법칙을 위반한다(물체 소실, 공중 부양). 모델 확장만으로 해결되지 않는다.
- **action 조건부 충실도**: "화질이 task 성공을 보장하지 않는다". controllability가 더 중요하다 (World-in-World).
- **장기 일관성**: 수십 초~수 분 이후 drift가 생기며 memory가 필요하다.
- **비용**: 14B 영상 모델의 실시간 추론이 난제다. DreamZero는 5.7초를 150ms로 줄여 38배 가속으로 7Hz 제어를 달성했다.

이후 방향은 pixel과 latent 논쟁의 지속, world model과 policy의 통합인 WAM(GR00T N2, 2026년 연말 예정), world model 평가 벤치마크 정립이다. 결론은 "'보기 좋은 영상'에서 '행동 가능한 시뮬레이터'로의 진화"다. 음성은 VLA와 world model을 융합한 world action model이 최근 몇 달 가장 많이 보이는 키워드이며, 행동하기 전에 결과를 먼저 상상하고 결정하는 방식이라고 설명한다.

### 3.5 주요 진영 (슬라이드 49~58)

**지형도 (슬라이드 49).** 발표자는 정답이 없는 상태라 빅테크도 지나치게 다양한 베팅 대신 각자의 전략에 맞는 방향을 선택적으로 추진한다고 본다. 진영은 다섯 가지다.

| 진영 | 핵심 베팅 | 대표 |
|---|---|---|
| A. 범용 로봇 두뇌 | 어떤 몸에도 붙는 하나의 모델 | PI, Skild AI, Google DeepMind |
| B. 풀스택 humanoid | 몸, 두뇌, 배치 데이터 루프 소유 | Tesla, Figure, 1X, Unitree, AgiBot |
| C. 플랫폼과 생태계 | 로보틱스의 'CUDA / Android' | NVIDIA, Hugging Face |
| D. World model 우선 | 미래 예측으로 물리를 이해한 뒤 행동 | Meta, AMI Labs, NVIDIA, 1X |
| E. 데이터 스케일링 | 값싼 human 데이터 + scaling law | Generalist, Figure, Tesla |

지형도 그림은 가로를 "VLM semantics ↔ world model physics", 세로를 "HW 수직계열화 ↔ SW 플랫폼"으로 두고 기업을 배치한다. Tesla, Figure, Boston Dynamics는 하드웨어 수직계열화와 VLM 쪽, Unitree와 AgiBot, 1X는 하드웨어 수직계열화와 world model 쪽, Google DeepMind, Generalist AI, Physical Intelligence, Skild AI는 소프트웨어 플랫폼과 VLM 쪽, NVIDIA, Meta와 AMI Labs는 소프트웨어 플랫폼과 world model 쪽이다. 슬라이드 주석은 발표자 해석에 따른 개념적 배치이며 진영 간 중첩이 있다고 밝힌다.

| 중국 | 압도적 하드웨어 양산과 가격 경쟁력 + 국가 주도 data factory + 자본시장 | Unitree: humanoid 가격 파괴 (R1 5,900달러), 상하이 STAR 상장 (2026.08, 첫날 +460%). AgiBot: 2026 상반기 humanoid 출하 1위 (8,400대, 점유율 약 44%), AgiBot World 데이터셋 (100만 개 이상 trajectory), GO-1 VLA, Genie Envisioner (영상 world model), 홍콩 IPO 추진. Galbot (sim + real), X Square (WALL-OSS 오픈), UBTech (Walker S2). 2026 H1 투자 935억 위안 (322건) |
| 국내 | 대기업의 하드웨어와 투자, 정부의 world model과 foundation model 사업 | 삼성: 레인보우로보틱스 지분 35%, RX 사업추진실 신설 (2026.07), Skild와 AMI Labs 투자. LG: 가정용 humanoid CLOiD, 정부 world model 컨소시엄 주관, Skild 투자, GR00T 도입. 현대차그룹: Boston Dynamics 신형 Atlas (CES 2026), 미국 메타플랜트 투입 계획, 2028년 연 3만 대 로봇 생산 체계 목표. RLWRLD (스타트업): dexterity 중심 robot foundation model, RLDX-1 (8.1B, 촉각과 토크 입력, 2026.05). 음성은 로보티즈 같은 하드웨어 강점 기업도 언급 |

풀스택 humanoid 기업의 공통점은 배치 → 데이터 → 모델 개선의 data flywheel 확보이며, Tesla 자율주행 방식의 재현 시도다. 발표자는 PI가 모델을 오픈소스로 공개해 VLA 분야의 사실상 표준 foundation model이 됐고 LLM 초기의 Llama 같은 위치라고 평가한다. 최근에는 API 기반 fine-tuning 서비스까지 내놓아 향후 사업 확장 방향이 가장 궁금한 회사로 꼽는다. Generalist와 Skild에 대해서는 LLM의 GPT-3 few-shot prompting(2020)에 대응하는 것이 로봇의 physical prompting(2026)이라며, 2026년 하반기의 화두를 fine-tuning에서 in-context learning으로의 전환으로 본다.

국내 정부 사업은 K-humanoid 연합 (2025.04, 2028 공용 foundation model 목표), 피지컬 AI 3대 메가프로젝트 (2026.06, 2030 '세계 1강' 목표), 국산 world model 사업 (2026.06, LG 주관, 서울대와 KAIST 참여), 국민성장펀드 (2026.07, 피지컬 AI 분야 대규모 투자 계획) 순으로 이어진다.

**핵심 질문별 진영의 답 (슬라이드 58).**

| 핵심 질문 | 입장 ① | 입장 ② |
|---|---|---|
| 무엇을 backbone으로? | VLM, semantics 상속 (PI, GDM) | Video와 world model, physics 상속 (NVIDIA N2, 1X, Meta) |
| 데이터는 어디서? | 실제 로봇 teleoperation (PI, AgiBot) | human video와 wearable (Generalist, Figure, EgoScale) |
| 새 task 학습 방법? | fine-tuning과 RL (PI π*0.6) | in-context, physical prompting (GEN-1.5, Skild S1) |
| 하드웨어? | 무관한 범용 두뇌 (PI, Skild, GDM) | 직접 제작, 풀스택 (Tesla, Figure, 1X, Unitree) |
| 모델 구조? | S2/S1 분리 (Figure, GR00T, GDM) | 단일 모델 (π0 계열) |

수렴하는 지점은 '느린 두뇌 + 빠른 몸' 계층, human 데이터 활용, RL post-training이다. 발표자는 정답이 정해지지 않은 지금이 연구자로서 진입하기 좋은 시점이라고 본다.

### 3.6 Base VLA의 확장 방향 (슬라이드 60~66)

**전체 구도 (슬라이드 60).** Base VLA(VLM backbone + flow matching action expert)를 가운데 두고 여섯 가지 결핍과 그에 대응하는 인간 능력을 짝지운다.

| 확장 | Base VLA의 결핍 | 대응하는 인간 능력 |
|---|---|---|
| 3D | 2D 중심 | 깊이 지각 |
| 촉각과 힘 | 시각 only | 촉각 |
| Memory | 과거 없음 (Markovian) | episodic memory |
| 비동기와 실시간 | 하나의 시계 | 반사 신경 |
| 추론 | 즉각 반응 | 숙고 |
| World model과 WAM | 예측 없음 | 상상 |

**3D (슬라이드 61).** VLM encoder는 2D image-caption으로 학습해 깊이와 기하 정보가 부족하지만 action은 3D 공간의 6-DoF 자세다 (인간도 한쪽 눈을 감고 바늘에 실을 꿰기 어렵다). 접근은 두 가지다.

- **Explicit**: point cloud와 depth를 입력에 추가한다. 3D Diffuser Actor, SpatialVLA, Any3D-VLA (실환경 zero-shot grasp 62.5% 대 33.3%).
- **Implicit**: 학습 시에만 3D foundation model(VGGT)에 alignment하고 추론에는 RGB만 쓴다. Spatial Forcing은 LIBERO 98.5%, 학습 3.8배 가속을 보고했다.

추세는 VGGT와 Depth Anything을 teacher나 pseudo-depth로 활용하는 것이며, 평가는 실환경 공간 변화로 옮겨 가고 있다. 음성은 DUSt3R와 VGGT 같은 3D foundation model과 3D reconstruction 모델을 함께 쓰려는 시도를 언급한다. Any3D-VLA의 입력 방식별 비교는 다음과 같다.

| 입력 방식 | Single-Trial SR (%) | Test SR (%) | Grasp SR (%) |
|---|---|---|---|
| 2D-only | 45.3 | 72.6 | 80.0 |
| Implicit-depth RGB | 55.8 | 78.9 | 85.3 |
| Implicit-3D RGB | 46.3 | 78.9 | 87.4 |
| RGBD image-plane | 56.8 | 76.8 | 87.4 |
| Point cloud와 2D patch fusion | 61.1 | 80.0 | 89.5 |

**촉각과 힘 (슬라이드 62).** 접촉 순간 그리퍼가 물체를 가리고(occlusion) 미끄러짐과 힘 변화는 ms 단위로 일어나지만, 카메라와 VLM은 약 10Hz다. 인간도 손끝 감각이 마비되면 시각이 멀쩡해도 물체를 떨어뜨린다. 인간의 반응 속도는 촉각에서 반사까지 60~90ms, 시각에서 교정까지 약 200ms다.

- ForceVLA: 6축 힘과 토크를 mixture-of-experts로 통합해 π0 대비 +23.2%.
- OmniVTA (2026): 시각과 촉각 world model + 60Hz 반사 제어기.
- FTP-1 (2026): 21종 센서, 약 3,000시간의 cross-sensor 촉각 foundation policy.
- 추세: 대규모 촉각 pre-training, 빠른 반사 루프, 센서 없는 힘 추정 (FD-VLA).
- 병목: 'Internet of touch'의 부재.

음성은 촉각 센서가 비싸고 잘 망가지며, 촉각 정보는 VLM pre-training에 없던 modality라 VLM이나 action expert를 추가로 학습해야 활용할 수 있다고 설명한다. 목표는 USB나 콘센트 꽂기 같은 dexterous manipulation의 정확도를 올리는 것이다.

**Memory (슬라이드 63).** Base VLA는 현재 프레임만 보는 Markovian 구조라 "소금을 넣었나?", "몇 번 닦았지?" 같은 상태를 추적하지 못한다. RoboMME (ICML 2026)는 14개 memory 변형을 비교했고 성공률은 기억 없음 17.9%, 최선의 memory 44.5%, 인간 90.5%였다 (counting, permanence, reference, imitation 4개 suite).

- MemoryVLA: perceptual + cognitive memory bank.
- PI MEM: 단기 영상 기억 + 장기 언어 기억, 최대 15분 task.
- RoboTTT: test-time training으로 8K step(약 5분) context. 슬라이드는 context 길이를 새로운 scaling 대상으로 본다.
- 추세: LLM context window 확장의 재현이며 in-context learning으로 진화 (GEN-1.5).

음성은 비디오를 스트리밍으로 받을수록 메모리가 선형으로 늘어나므로 효율화하고 중요한 정보 위주로 저장하는 연구가 많다고 덧붙인다.

**비동기와 실시간 (슬라이드 64).** 동기식은 추론과 실행을 번갈아 해 동작이 끊기고, 비동기식은 실행 중에 다음 chunk를 준비해 끊김이 없다. 문제는 chunk 경계의 끊김과 추론 동안 낡아 버린 observation이다 (인간은 피아니스트가 연주하며 다음 악보를 읽듯 처리한다).

- 이중 시계: Helix 7~9Hz / 200Hz, Fast-in-Slow 117.7Hz.
- Real-Time Chunking (PI): 실행 중 다음 chunk를 생성하되 실행될 구간은 고정하고 나머지를 inpainting한다.
- 추세: 지연을 학습 분포에 포함한다 (training-time RTC, VLASH).

슬라이드의 결론은 추론 지연이 '엔지니어링'이 아니라 '모델링' 문제이며 LLM serving의 streaming, speculative decoding과 유사하다는 것이다.

**추론 (슬라이드 65).** 문제는 두 가지다. pixel에서 action으로 직행해 중간 '생각'이 없고, VLA 학습 중 VLM 능력이 catastrophic forgetting으로 손상된다.

- **Explicit reasoning**: ECoT는 계획, subtask, bbox, 그리퍼 위치를 먼저 추론한다 (OpenVLA 대비 +28%). CoT-VLA는 subgoal 이미지를 생성한 뒤 행동한다 (visual CoT). Gemini Robotics 1.5는 "Thinking VLA"다.
- **Latent / continuous reasoning (2026)**: LaRA-VLA (지연 최대 90% 감소), Continuous Reasoning VLA.
- **VLM 지식 보존**: Knowledge Insulation, Actions as Language (ICLR 2026).

LLM 추론의 흐름(chain-of-thought → latent reasoning)이 VLA에서 반복되며, 발표자는 이 방향이 연구실의 강점과 직결된다고 말한다. 음성은 속도를 위해 latent 공간에서 추론하는 쪽으로 가고 있으며, 이는 앞의 latent world model 방향과도 동기가 일치한다고 설명한다.

**World model과 WAM (슬라이드 66).** VLA는 VLM backbone으로 semantics를, WAM은 video model backbone으로 physics를 상속한다. WAM은 미래 observation(영상)과 action을 함께 예측하며 cascaded(영상 계획 → IDM)와 joint(영상 + action 동시 예측) 방식이 있다.

- DreamZero (NVIDIA): 14B 영상 diffusion 기반, VLA 대비 2배 이상 일반화, 7Hz 제어. GR00T N2의 기반.
- Cosmos Policy: 영상 모델을 그대로 policy로 쓴다 (LIBERO 98.5%).
- mimic-video: VLA 대비 10배 sample efficiency.
- 과제: 무거운 추론과 약한 언어 grounding. 하이브리드 방향으로 π0.7은 경량 world model로 subgoal을 생성한다.

발표자는 VLA와 WAM의 경쟁을 2026년 가장 큰 구조적 변화 후보로 본다. 음성은 WAM이 아직 무겁고 언어 이해가 약하지만 방향성 자체는 올해 가장 큰 구조적 변화라고 평가한다.

## 5. 한계와 향후 과제 (Limitations and Future Work)

### 5.1 분야의 열린 문제 (슬라이드 68~73)

발표자는 "문제의식이 곧 연구 방향"이라며 문제의식과 연구 방향을 짝지운다.

| 문제의식 | 연구 방향 | 대표 키워드 |
|---|---|---|
| 로봇 데이터가 부족함 | 대체 데이터 활용 | human video, UMI, 시뮬레이션, 합성 데이터, world model 생성 |
| 처음 보는 상황에서 실패함 | 일반화 | co-training, compositional generalization, cross-embodiment |
| 시연 수준을 넘지 못함 | 자기 개선 | RL post-training (real, sim, world model) |
| 정교한 손 작업 불가 | dexterity | dexterous hand, 촉각, 대규모 grasp 합성 |
| 긴 작업과 기술 누적 불가 | 기억과 지속 학습 | memory, in-context learning, continual learning |
| 느리고 무거움 | 효율 | 경량 VLA, on-device, asynchronous inference |
| 성능을 믿을 수 없음 | 평가와 안전 | 벤치마크, world model 기반 평가, 실패 감지와 복구 |

**데이터 (슬라이드 69).** human egocentric video가 가장 scalable한 데이터원이다. EgoMimic은 사람 손 데이터 1시간이 로봇 데이터 1시간보다 낫다고 보고했고, EgoScale(NVIDIA)은 2만 시간에서 log-linear scaling과 22-DoF 손 +54%를 보였다. Ψ0(RSS 2026)는 human 800시간과 robot 30시간으로 10배 데이터 baseline을 넘었다. PI는 로봇 pre-training이 충분히 다양할 때 human에서 robot으로의 전이가 '창발'한다고 보고했다. 핵심 질문은 사람 손과 로봇 몸의 차이(embodiment gap) 해소, 그리고 co-training과 분리 학습 가운데 무엇이 나은지다. 시뮬레이션과 합성 데이터로는 DexMimicGen, RoboCasa365 (365 tasks, 2,200시간 이상), DreamGen이 있다. 슬라이드는 '로봇 없이 모은 데이터로 로봇 가르치기'를 2026년 가장 뜨거운 방향으로 꼽는다.

**일반화 (슬라이드 70).** open-world 일반화는 π0.5가 다중 로봇, web, subtask co-training으로 처음 보는 가정 청소를 해낸 사례다. compositional generalization(학습한 기술의 새로운 조합)은 LIBERO-Gen Task-CG 21%로 모델이 스스로 조합하지 못하며, π0.7(2026.04)이 조합적 일반화의 초기 신호를 보였다. cross-embodiment는 HPT(embodiment별 stem + 공유 trunk), X-VLA(soft prompt, 0.9B), One Hand to Rule Them All(처음 보는 손 zero-shot 81.9%)이 대표다. 슬라이드는 LLM의 'GPT 모먼트'(few-shot 일반화)가 로봇에는 아직 오지 않았으며 일반화가 가장 근본적인 미해결 문제라고 본다.

**RL post-training (슬라이드 71).** imitation learning은 시연자 수준이 상한이고 실패로부터 학습할 수 없다. 발표자는 시연이 대부분 성공 trajectory라 실패했을 때 회복하는 법을 배우지 못한다고 설명한다.

- 실환경 RL: HIL-SERL(사람 개입 + RL, 1~2.5시간 학습으로 거의 완벽한 성공률), DSRL(거대 policy는 고정하고 diffusion noise 입력만 RL로 조정), π*0.6 / RECAP(시연 + 자율 rollout + 사람 교정 → throughput 2배, 실패 절반).
- 시뮬레이션 RL: SimpleVLA-RL (task당 시연 1개 + RL로 LIBERO-Long 17.3% → 91.7%).
- world model 속 RL: WMPO.
- LLM과의 평행: SFT → RLHF와 RLVR. reward 설계와 안전한 탐색이 핵심 난제다.

슬라이드는 "pre-training으로 '할 줄 알게', RL로 '잘하게'"라고 요약하고 LLM post-training 노하우가 직접 전이되는 영역으로 본다. 음성은 이런 방법도 test time에 새로운 상황을 만나면 성능이 크게 떨어질 수 있다고 단서를 단다.

**그 밖의 방향 (슬라이드 72).**

| 방향 | 문제의식 | 대표 연구 |
|---|---|---|
| Dexterity | 손으로 하는 정교한 조작 | Dex1B (10억 grasp 합성), Dexonomy, DexUMI, RLWRLD RLDX-1 |
| Continual learning | 새 기술 학습 시 기존 기술과 VLM 지식 망각 | LifeLong-RFT (RSS 2026), TRI LBM co-training |
| 효율과 배치 | 거대 모델의 지연과 비용 | SmolVLA (0.45B), Gemini Robotics On-Device, Jetson Thor |
| 평가 | 포화된 sim, 비싼 실환경 | RoboArena, AutoEval, PolaRiS (RSS 2026), world model 평가 |
| 실패 감지와 안전 | 실패의 인지와 복구 | AHA, FailSafe, OopsieVerse (RSS 2026) |
| humanoid whole-body control | 이동과 조작의 통합 | GEAR-SONIC, HOMIE, Figure Helix 02 S0 |

RSS 2026 주요 세션은 VLA, World Models & Memory, Humanoids, Imitation Learning(3개 세션), RL, Datasets & Benchmarks였고 Outstanding Paper는 FlashSAC(off-policy RL, KAIST 연구진 참여)였다. 슬라이드는 어느 방향이든 아직 '정답 논문'이 없어 문제 정의 자체가 기여가 되는 시기라고 본다.

**결론 (슬라이드 73).**

1. **열린 분야**: 2023년 이후 급성장했지만 consensus가 없는 관점 경쟁 단계다.
2. **핵심 병목은 데이터와 일반화**: 벤치마크 점수와 실제 성능의 간극이 있고 scaling 논쟁이 진행 중이다.
3. **LLM 발전 경로의 압축 반복**: pretrain → post-train → RL, chain-of-thought → latent reasoning, context → in-context.
4. **향후 2~3년의 관전 포인트**: VLA 대 WAM, teleoperation 대 human video, fine-tuning 대 in-context.

전망으로 공장과 물류의 제한적 배치는 진행 중이지만 가정용 범용 로봇은 아직 먼 미래라는 신중론이 공존한다(MIT Technology Review, 2026.10). 발표자는 다루는 task가 아직 기초적이라 사람과 자연스럽게 상호작용하는 로봇이 나오기까지는 많은 시간이 걸릴 것이라고 보면서, Physical AI를 'LLM 이후의 다음 frontier'로 정리한다.

### 5.2 자료 자체의 한계

- 분야 개관 강의라 개별 방법의 세부(학습 설정, ablation)는 다루지 않는다. 수치는 슬라이드에 출처만 표기된 2차 인용이다.
- 시장 전망, 밸류에이션, 출하량 같은 산업 수치는 시점 의존성이 크고(2026년 10월 기준) 보도 기반 값이 섞여 있다 (예: PI 약 110억 달러 라운드 "보도").
- 진영 지형도는 슬라이드 주석이 밝히듯 발표자 해석에 따른 개념적 배치다.
- 데모 영상에 대해서는 발표자 스스로 잘 나온 것 위주로 정리됐을 수 있어 실제 성능과 다를 수 있다고 단서를 단다.
- 자동 자막 기반 transcript라 고유명사 인식 오류가 많다 (예: "리베로"는 LIBERO, "엔드 벡터"는 end-effector, "얼티 1"은 RT-1). 이 요약은 슬라이드 표기로 고유명사를 바로잡았다.

## 6. 관련 연구 (Related Work)

강의가 언급하는 연구 가운데 이 wiki에 페이지가 있는 것은 다음과 같다.

- **데이터와 시뮬레이션**: RoboCasa와 RoboCasa365, Genesis, LeRobot.
- **in-context 학습**: GEN-1.5 (physical prompting), Skild AI S1.
- **추론**: LaRA-VLA (latent reasoning).
- **실패 감지**: FailSafe.

같은 연구실(DSBA)의 다른 세미나 영상으로 Graph based RAG 논문 리뷰가 이 wiki에 있다. 같은 주제의 한국어 입문 영상으로 엥지유니버스의 Physical AI 핵심 논문 14편 리뷰가 있다.

## 7. 용어집 (Glossary)

도메인 공통 용어(policy, action chunk, flow matching, world model 등)는 `wiki/overviews/glossary-physical-ai.md`를 따른다. 여기에는 이 강의에 고유하거나 강의가 특정 의미로 쓰는 용어만 둔다.

| 용어 | 뜻 |
|---|---|
| Physical AI | 물리 세계를 지각하고 이해하고 추론해서 그 안에서 직접 행동하는 AI (NVIDIA 정의). 학계 용어 Embodied AI와 사실상 같은 대상 |
| Base VLA | 강의가 확장 방향의 기준으로 삼는 표준 구조. VLM backbone + flow matching action expert |
| Moravec's Paradox | 인간에게 어려운 고차 추론은 AI에게 쉽고, 인간에게 쉬운 감각운동은 AI에게 어렵다는 역설 |
| bought, not scraped | 로봇 데이터는 웹에서 수집하는 것이 아니라 작업 1시간이 데이터 1시간이 되도록 비용을 들여 만든다는 표현 |
| Task-CG | LIBERO-Gen의 compositional generalization 평가. 학습한 기술의 새 조합 성공률 (π0.5 21.2%) |
| Mode-1 / Mode-2 | LeCun의 구분. Mode-1은 지각에서 즉각 행동, Mode-2는 world model로 결과를 시뮬레이션하며 최적 행동을 탐색 |
| JEPA | Joint-Embedding Predictive Architecture. pixel이 아니라 latent 표현 공간에서 미래를 예측하는 Meta와 LeCun 계열 구조 (V-JEPA 2) |
| data hands | Generalist AI가 실세계 상호작용 데이터를 모으는 착용형 장치 |
| Omni-bodied | Skild AI가 내세우는 개념으로, 어떤 형태의 로봇에도 붙는 하나의 모델 |
| Internet of touch | 촉각 데이터에는 인터넷 규모의 공개 데이터가 없다는 병목을 가리키는 슬라이드 표현 |
| UMI | Universal Manipulation Interface. 로봇 없이 카메라 달린 손잡이형 그리퍼로 시연을 모으는 장치 |
