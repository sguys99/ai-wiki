## 한 줄 요약 (One-line Summary)

RT-1은 로봇의 다음 제어 명령인 action을 구간별로 분류해 실시간 실행과 일반화를 함께 평가했다. RT-2는 같은 구간 표현을 웹에서 학습한 시각 언어 모델의 어휘에 연결해, 익숙한 동작으로 낯선 대상이나 목적지를 선택할 수 있는지 평가했다.

## 2. 주요 기여 (Key Contributions)

- RT-1의 기여는 토큰화, 데이터 규모, 실행 속도를 실제 로봇에서 함께 검증한 데 있다. 선행 연구인 Trajectory Transformer는 시뮬레이션에서 평가했고 Gato의 실제 로봇 평가는 블록 쌓기에 집중했다.
- RT-2는 웹 질문에는 자연어로, 로봇 지시문(instruction)에는 action 토큰으로 답하도록 같은 모델을 학습했다. 지시문에서 대상과 목적지를 새로 해석해도 집거나 옮기는 동작은 로봇 시연 데이터(demonstration)에서 익힌 범위에 머문다.
- 발표자는 같은 모델의 학습 조건을 바꾼 실험과 크기까지 달라지는 모델 간 비교를 구분한다. 두 논문의 미학습 평가도 서로 다른 과제를 쓴다.

## 3. 방법론 및 아키텍처 (Methodology and Architecture)

| 항목 | RT-1 | RT-2 |
|---|---|---|
| 입력에서 출력까지 | 이미지 6장과 문장 임베딩을 FiLM으로 결합. TokenLearner가 이미지당 81개 표현을 8개로 줄이면 Transformer가 action을 예측 | 웹에서 이미지와 텍스트를 학습한 PaLI-X 또는 PaLM-E가 지시문을 읽고 정수 토큰을 차례로 생성 |
| 출력과 시간 | 같은 시점의 팔 7개, 이동 베이스 3개, 모드 1개를 병렬로 예측 | 종료 1개와 팔 7개로 한 시점을 표현. 로봇 제어에서는 유효한 토큰만 선택 |
| 데이터 | 로봇 13대, 17개월, 약 13만 건, 지시문 744개 | 웹 질의응답 및 캡션과 로봇 시연을 혼합. 로봇 비중은 PaLI-X 약 50%, PaLM-E 약 66% |
| 실행 | 3,500만 파라미터, 로봇에서 3Hz | 클라우드에서 550억 파라미터 모델 1~3Hz, 50억 모델 약 5Hz |

두 모델은 연속 차원의 범위를 256개 구간으로 나눈다. 하나의 시점에서 여러 차원을 출력하는 방식과 여러 시점의 명령을 묶는 방식은 별개다. RT-1에서 구간별 확률은 같은 장애물을 왼쪽이나 오른쪽으로 피한 시연을 모두 표현할 수 있다.

## 4. 주요 결과와 벤치마크 (Key Results and Benchmarks)

| 실험 | 강의가 보고한 결과 |
|---|---|
| RT-1 평가 | 학습 과제 97%, 익숙한 요소의 새 조합 76%, 방해 물체 83%, 새 배경 59%. 단봉 회귀로 바꾸면 각각 68%, 43%, 37%, 35% |
| RT-1 데이터 구성 | 미학습 조건 평균 73%. 과제를 유지하고 데이터를 약 절반만 쓰면 50%, 데이터를 97% 남기고 과제를 25% 줄이면 54% |
| 이질적 데이터와 실행 | 시뮬레이션에서만 본 물체의 학습 스킬 23%에서 87%. KUKA 데이터 추가 시 상자에서 물체 집기 22%에서 39%. 새 주방에서 SayCan 실행 성공률은 BC-Z 13%, RT-1 67% |
| RT-2 학습 방식 | 50억 모델의 미학습 평균은 처음부터 학습 9%, 웹 학습 후 로봇만 추가 학습 42%, 웹 데이터 혼합 44%. 550억 모델은 뒤의 두 조건에서 52%, 63% |
| RT-2 일반화 | 새 물체, 배경, 환경에서 RT-1 32%, RT-2 두 모델 모두 62%. 기호, 추론, 인물 평가에서는 RT-1 17%, RT-2 PaLI-X 60%, PaLM-E 40% |

## 5. 한계와 향후 과제 (Limitations and Future Work)

RT-1의 분류 실험에서 비교한 연속 출력은 단봉 회귀다. 여러 이동 경로를 생성할 수 있는 diffusion이나 flow matching과의 우열은 이 실험으로 판정할 수 없다. RT-2의 창발 과제는 연구진이 고른 지시문마다 다섯 번 평가했고 주된 동작은 집어 옮기기였다. 자연어 계획을 먼저 쓰는 변형은 정성 사례로 제시했다.

RT-2의 학습 코드와 가중치, 웹 데이터의 공개 제약은 같은 결과를 재현하는 데 영향을 준다. 커리큘럼은 다음 회차에서 Open X-Embodiment와 OpenVLA를 읽고, 이어 ACT와 Mobile ALOHA로 한 번에 예측하는 시점 수를 비교한다.

## 7. 용어집 (Glossary)

| 용어 | 이 강의에서의 역할 |
|---|---|
| FiLM | 문장 임베딩으로 이미지의 채널별 응답을 조절한다 |
| TokenLearner | 이미지에서 중요한 위치의 정보를 모아 소수의 시각 토큰을 만든다 |
| SayCan | 언어 모델로 단계를 계획하고 실행은 로봇에 맡겨 계획 성공과 실제 실행을 따로 측정한다 |
| co-fine-tuning | 웹 예제와 로봇 시연을 섞어 같은 모델을 추가 학습한다 |
| Action as Text | 로봇 명령의 각 차원을 정수 토큰으로 표현해 언어 모델의 출력 어휘로 다룬다 |
