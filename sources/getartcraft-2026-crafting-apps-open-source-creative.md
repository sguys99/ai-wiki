## 한 줄 요약 (One-line Summary)

Crafting Apps는 ArtCraft 팀이 공개한 13종의 오픈소스 데스크톱 창작 앱 묶음으로, 이미지 편집부터 CAD와 스프레드시트까지 전문가용 도구를 Rust로 처음부터 다시 만들고 CLI, JSON 제어 채널, MCP 서버로 AI 에이전트가 직접 조작할 수 있게 한다는 것을 소개하는 제품 페이지다.

페이지는 세 구획으로 나뉜다. "01 Crafting Apps"는 전체 소개와 설치 안내, "02 The lineup"은 13개 앱 카드, "03 Principles"는 모든 앱이 공유하는 6개 원칙이다.

## 2. 주요 기여 (Key Contributions)

- **13종 창작 앱 라인업**: 이미지 편집, 벡터 일러스트, 영상, 사진, PDF, 모션 그래픽, 페이지 레이아웃, 인터페이스 디자인, 문서 작성, 오디오, 프레젠테이션, CAD, 스프레드시트를 한 계열로 묶는다.
- **순수 Rust 네이티브 구현**: Electron이나 web view로 감싸지 않고 Rust로 컴파일한 실제 데스크톱 앱이라고 밝힌다.
- **에이전트 조작 인터페이스(Agent-ready)**: 모든 앱을 CLI, JSON 제어 채널, MCP 서버로 구동할 수 있게 만들어 자동화와 AI 에이전트를 겨냥한다.
- **익숙한 UI**: 전문가가 이미 아는 레이아웃, 도구, 단축키를 그대로 따라 다시 배울 필요가 없게 한다.
- **로컬 우선**: 모든 작업이 사용자의 기기와 파일에서 실행되고 클라우드 왕복이 없다.
- **WebAssembly 빌드**: FilmCraft를 뺀 12개 앱이 브라우저 탭에서도 실행된다.

## 3. 방법론 및 아키텍처 (Methodology and Architecture)

### 3.1 앱 라인업

| 번호 | 앱 | 분야 | 페이지의 한 줄 소개 | 상태 | 플랫폼 |
|---|---|---|---|---|---|
| 01 | PhotoCraft | Image editor | 이미 사용법을 아는 오픈소스 이미지 편집기 | Early alpha | macOS, Windows, Linux, Web |
| 02 | VectorCraft | Vector illustration | 순수 Rust로 다시 구상한 빠른 벡터 일러스트 | In development | macOS, Windows, Linux, Web |
| 03 | FilmCraft | Video editor | Rust로 처음부터 다시 만든 전문 영상 편집 | In development | macOS, Windows, Linux |
| 04 | LightCraft | Photo library & raw developer | 자기 기기에서 실행되는 사진 라이브러리와 raw 현상기 | In development | macOS, Windows, Linux, Web |
| 05 | PdfCraft | PDF workbench | 읽기, 정리, 합치기, 분할, 보안 처리 | Early alpha | macOS, Windows, Linux, Web |
| 06 | EffectCraft | Motion graphics & VFX | 순수 Rust 모션 그래픽과 시각 효과 | In development | macOS, Windows, Linux, Web |
| 07 | DesignCraft | Page layout & publishing | 순수 Rust로 다시 만든 페이지 레이아웃과 출판 | In development | macOS, Windows, Linux, Web |
| 08 | FigCraft | Interface design | 인터페이스 디자인과 프로토타이핑 | Early alpha | macOS, Windows, Linux, Web |
| 09 | WordCraft | Word processing | 빠른 오픈소스 문서 작성 | In development | macOS, Windows, Linux, Web |
| 10 | SoundCraft | Digital audio workstation | 녹음, 편집, 믹싱 | In development | macOS, Windows, Linux, Web |
| 11 | DeckCraft | Presentations & slide shows | 동적 슬라이드 제작과 발표 | In development | macOS, Windows, Linux, Web |
| 12 | CADCraft | Computer-aided design & drafting | 빠른 오픈소스 설계와 제도 | In development | macOS, Windows, Linux, Web |
| 13 | GridCraft | Spreadsheets & data analysis | 스프레드시트와 데이터 분석 | In development | macOS, Windows, Linux, Web |

모든 카드에 "Installers ready" 표시가 있다. 성숙도는 Early alpha 3개(PhotoCraft, PdfCraft, FigCraft), In development 10개다. Web 표시가 없는 앱은 FilmCraft 하나이며, 원칙 6번의 브라우저 지원 목록에서도 FilmCraft만 빠진다.

### 3.2 공통 원칙 6개

| 번호 | 원칙 | 내용 |
|---|---|---|
| 01 | Open source | 모든 코드를 GitHub에 permissive license로 공개한다. 읽고, fork하고, 그 위에 만들 수 있다 |
| 02 | Native, not wrapped | 순수 Rust를 macOS, Windows, Linux용 실제 데스크톱 앱으로 컴파일한다. Electron도 web view도 쓰지 않는다 |
| 03 | Familiar from day one | 현업 전문가가 이미 아는 레이아웃, 도구, 단축키를 따른다 |
| 04 | Your files, your machine | 모든 처리가 사용자의 파일 위에서 로컬로 실행된다 |
| 05 | Agent-ready | 모든 앱을 CLI, JSON 제어 채널, MCP 서버로 구동할 수 있다 |
| 06 | Also in your browser | 12개 앱이 WebAssembly로도 컴파일되어 브라우저 탭에서 실행된다 |

페이지는 이 원칙을 "Built the hard way"라는 문구로 묶고 모든 앱이 Rust로 처음부터 작성되어 같은 규칙을 따른다고 적는다.

### 3.3 배포 방식

- **ArtCraft Launcher**: 페이지가 권장하는 설치 경로다. 13개 앱을 모두 설치하고 최신 상태로 유지한다. 내려받기 링크는 craft-launcher v0.3.2의 Linux x86_64 Flatpak 패키지를 가리킨다.
- **앱별 설치기**: 각 앱 상세 페이지에 개별 설치기가 있다.
- **커뮤니티**: 다음에 다시 만들 앱 요청, 초기 빌드 테스트, 로드맵 공유를 ArtCraft Discord에서 진행한다.

## 4. 주요 결과와 벤치마크 (Key Results and Benchmarks)

제품 소개 페이지라 성능 수치나 벤치마크가 없다. 확인할 수 있는 정량 정보는 앱 수(13개), 브라우저 지원 앱 수(12개), Early alpha 앱 수(3개), launcher 버전(v0.3.2)뿐이다. 앱 스크린샷은 각 앱이 다루는 대표 작업(Curves 조정, 다중 트랙 타임라인, auto layout, 평면도 해칭, 조건부 서식 등)을 보여 준다.

## 5. 한계와 향후 과제 (Limitations and Future Work)

- 13개 앱 모두 Early alpha 또는 In development 단계라 실무 대체 수준은 이 페이지만으로 판단할 수 없다.
- "Agent-ready" 원칙은 CLI, JSON 제어 채널, MCP 서버를 언급할 뿐 명령 체계나 프로토콜 세부는 페이지에 없다.
- 페이지가 직접 내려받기를 제공하는 launcher 패키지는 Linux Flatpak(x86_64) 하나다. macOS와 Windows 설치기는 앱별 페이지로 넘긴다.
- "More crafts on the way"라고 밝혀 라인업이 늘어날 예정이다.

## 6. 관련 연구 (Related Work)

- **ArtCraft (storytold/artcraft)**: 같은 팀의 대표 제품으로, AI 이미지와 영상 생성을 위한 IDE다. 페이지 바닥글은 ArtCraft를 "controllable AI image and video를 위한 오픈소스 스튜디오"로 소개한다. Crafting Apps는 ArtCraft와 별개인 일반 창작 도구 계열이다.
- 페이지는 특정 상용 제품명을 언급하지 않고 "이미 사용법을 아는" 도구라는 표현만 쓴다.

## 7. 용어집 (Glossary)

| 용어 | 뜻 |
|---|---|
| Crafting Apps | ArtCraft 팀이 만드는 13종 오픈소스 창작 앱 계열의 총칭 |
| ArtCraft Launcher | 모든 Crafting App을 설치하고 갱신하는 통합 설치기 (storytold/craft-launcher) |
| Agent-ready | 앱을 CLI, JSON 제어 채널, MCP 서버로 외부에서 구동할 수 있게 설계했다는 원칙 |
| JSON control channel | 실행 중인 앱에 JSON 메시지로 명령을 보내는 제어 경로 |
| Native, not wrapped | Electron이나 web view 래퍼 없이 네이티브 바이너리로 컴파일한다는 원칙 |
| Early alpha / In development | 페이지가 앱별로 표기하는 성숙도 단계 |
