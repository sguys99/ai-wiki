## 읽는 법 (How to Use)

난이도가 아니라 매체 유형으로 가른 구성이다. 영상으로 감을 잡고 → repo로 실물을 만지고 → 책으로 배경을 채운 뒤 → 논문으로 뿌리를 확인하는 순서가 은근히 깔려 있다. 논문 다섯 편은 이 wiki가 이미 여러 곳에서 다뤄 온 agentic reasoning의 원류(tool use·추론·자기반성)다.

## 한계 (Limitations)

- **링크 불투명**: 25개 전부 단축 URL. 최종 목적지 특정 불가.
- **입문 편향**: 속성 강좌·팁 위주. 심화는 논문 다섯 편에 몰려 있다.
- **자기 홍보**: 마지막 커뮤니티는 저자 본인 채널 유입 장치.
- **후속 권장**: 여기 걸린 것 중 원본이 확실한 자료(ReAct PDF, 공식 Claude Code repo 등)는 각각 정식 `papers`·`repos`로 따로 ingest하는 편이 이 목록 한 장보다 값지다.
