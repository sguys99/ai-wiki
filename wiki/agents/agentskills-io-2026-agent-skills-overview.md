## 요약 (Summary)

agentskills.io는 Agent Skills 오픈 표준의 공식 문서 사이트다. 포맷 정의와 progressive disclosure 3단계는 [[agents/agentskills-agentskills|소스 저장소]]와 겹치지만, 이 사이트가 따로 보여주는 건 **Client Showcase**다. 40여 개 AI 도구가 같은 포맷을 채택했다는 사실을 로고 캐러셀로 나열한다. 코딩 에이전트부터 IDE, 데이터 플랫폼, 헬스케어까지 도메인을 넘나든다.

## 채택 생태계 (Ecosystem)

눈에 띄는 건 경쟁 관계인 벤더들이 나란히 들어와 있다는 점이다. OpenAI Codex, Google Gemini CLI, Mistral Vibe, Microsoft(GitHub Copilot·VS Code), JetBrains Junie가 하나같이 Anthropic 발 포맷을 지원한다. 특정 벤더의 것을 넘어 업계 공통 규격으로 자리잡아 간다는 신호로 읽힌다.

사이트가 나열한 클라이언트(발췌): Junie, Gemini CLI, Autohand, OpenCode, OpenHands, Mux, Cursor, Amp, Letta, Firebender, Goose, GitHub Copilot, VS Code, Claude Code, Claude, OpenAI Codex, Piebald, Factory, pi, Databricks Genie Code, Agentman, TRAE, Spring AI, Roo Code, Mistral Vibe, Command Code, Ona, VT Code, Qodo, Laravel Boost, Emdash, Snowflake Cortex Code, Kiro, Workshop, Google AI Edge Gallery, nanobot, fast-agent, bub, Tabnine, Vita, Superconductor, Deep Code.

## 한계 (Limitations)

쇼케이스가 말해주는 건 채택했다는 사실뿐이다. 클라이언트마다 구현을 얼마나 충실히 했는지, 서로 잘 맞물리는지는 알 수 없다. 목록 자체도 자주 바뀌니, 이 페이지는 ingest 시점을 찍어둔 스냅샷 정도로 봐야 한다.
