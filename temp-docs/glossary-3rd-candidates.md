# 용어집 3차 갱신 등재 후보 (Phase 0-3 (b))

작성일: 2026-09-06. `temp-docs/contents-renewal.md` Phase 0-3의 (b) 항목 산출물이다. agents와 llms 도메인에서 아직 용어집에 없는데 한글 직역 표기가 저장소에 실제로 퍼져 있는 용어를 빈도 실측으로 뽑았다. 작성 시점에는 후보 표까지가 범위였고, 2026-09-06 사용자 승인으로 7행을 등재했다. **승인 결과와 실행 내역은 6절에 있다.** 2절 표의 `권고` 열은 승인 전 조사 결과 그대로 두어 판단 근거를 보존한다.

계량 방식은 `temp-docs/ingest-upgrade-plan.md` Phase 5-1의 사전 계량 방식을 승계한다. 후보를 실제로 glossary-agents(전 카테고리)에 넣고 `lint_terms.py`를 돌려 신규 위반 건수를 실측했으며, 추측값은 쓰지 않았다.

## 1. 측정 방법

- 대상은 `lint_terms.py`의 `collect_targets`와 동일하다. `sources/*.md`, `wiki/**/*.md`, `index.md`에서 용어집 3편을 뺀 438개 문서다.
- 라인 선별도 lint와 동일하다. frontmatter, 코드 펜스, 인라인 코드, wikilink, URL, 라틴 괄호 병기를 마스킹하고 `lint-terms: ignore`와 `off/on` 블록을 제외했다.
- **신규 위반**은 후보를 glossary-agents 용어 표에 임시로 추가하고 lint를 실행해 얻은 실측값이다. 한 줄에 같은 표기가 여러 번 나와도 lint와 같이 1건으로 센다.
- **physical-ai 영향**은 신규 위반 중 `wiki/physical-ai/` 경로와 frontmatter가 `category: physical-ai`인 sources를 합한 값이다. physical-ai는 완료 카테고리라 이 값이 그대로 rework 비용이다.
- **오탐 위험**은 매치를 품은 최대 한글 어절을 뽑아, 매치가 어절 첫머리가 아닌 경우(앞에 다른 형태소가 붙은 경우)를 센 값이다. Phase 5-1이 "결합도"와 "이동 조작"을 기각할 때 쓴 것과 같은 검토다.
- 조사가 붙어 늘어난 어절(`하네스를`, `백본이`)은 오탐이 아니다. lint가 의도적으로 잡는 형태다. 접두사가 붙은 파생형(`재인덱싱`, `코파인튜닝`)도 오탐이 아니라 진짜 위반으로 본다 (Phase 5-5 판정 승계).

후보 풀은 207개 표기를 훑어 그중 저장소에 실제로 등장한 118개를 계량했고, 아래 표에는 판단이 필요한 23개만 올렸다.

## 3. 요약

- **등재 권고 6행** (1~6번): 신규 위반 합계 148건, 고유 대상 파일 65개, physical-ai 영향 14건. 여섯 중 셋(5, 6, 1번)은 신규 행이 아니라 기존 행의 금지 표기 칸을 채우거나 좁히는 작업이다.
- **보류 8건** (7~14번): 전부 canonical 방향 결정이 선행이거나 physical-ai rework가 이득보다 큰 경우다.
- **기각 6건** (15~20번): 의미 분기, 부분 문자열 충돌, 방향 역전, 절대량 부족 중 하나에 해당한다.
- **이관 1건** (21번): physical-ai 도메인이라 Phase 7-1 소관이다.
- **조치 불요와 관찰 2건** (22~23번).

등재 권고 6행을 모두 반영하면 `lint_terms --all`은 117건에서 265건이 된다. physical-ai 게이트는 14건이 새로 걸리므로 등재와 같은 커밋에서 정리해야 0건이 유지된다.

## 5. `SUBSTRING_EXCEPTIONS` 추가 제안

**등재 권고 6행에는 추가가 필요 없다.** 여섯 표기 모두 충돌 어절이 0건이다.

보류 후보를 나중에 등재할 경우에만 다음이 필요하다.

| 조건 | 필요한 예외 |
|---|---|
| 8번 `질의`를 등재하는 경우 | `"질의": ["품질의", "물질의", "성질의"]` (실측 20건, 1건, 1건). 별개 개념인 `질의응답` 17건은 예외가 아니라 별도 판단이 필요하다. 등재하지 않는 편이 낫다는 것이 이 조사의 결론이다 |
| 16번 `툴`을 등재하는 경우 | `"툴": ["툴셋", "툴체인", "툴링", "툴바", "툴킷"]`. 예외가 5개나 필요하다는 점 자체가 기각 근거다 |

다음은 예외로 등재하지 **않는다**. 접두사가 붙은 파생형이라 같은 개념을 같은 번역어로 쓴 진짜 위반이다 (Phase 5-5 판정 승계).

- `재인덱싱` (12번 등재 시): re-indexing이므로 `인덱싱`과 같은 처리를 받아야 한다
- `코파인튜닝` (7번 등재 시): co-fine-tuning의 미등재 음차이고 glossary-llms의 canonical은 `co-fine-tuning`이다
