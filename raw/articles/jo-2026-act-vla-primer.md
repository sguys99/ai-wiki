## Ⅰ. 모델 등장 배경

### 1. ACT 연구의 등장 배경

정밀한 로봇 조작은 작은 오차에도 쉽게 실패합니다. 배터리를 슬롯에 끼우거나, 컵 뚜껑을 열거나, 얇은 물체를 양손으로 맞잡아 조작하는 작업은 몇 mm 수준의 위치 차이만으로도 전체 과정이 무너질 수 있습니다.

![정밀 조작 예시](https://static.wikidocs.net/images/page/366371/gh_4fb565d0c819.png)

ACT 논문은 이러한 정밀 조작을 사람의 시연 데이터로 학습할 수 있는지를 다룹니다. 논문에서는 시연 데이터를 수집하기 위한 저비용 양팔 원격조작 시스템도 함께 제안하지만, 알고리즘 관점에서 더 중요한 문제는 모방학습에서 발생하는 누적 오차입니다.

#### 1-1. 한 동작씩 예측하는 방식의 한계

일반적인 모방학습은 현재 관측을 보고 다음 한 동작을 예측합니다.

```
Copy
현재 관측 → 다음 동작
```

이 방식은 단순하지만, 긴 조작 작업에서는 작은 오차가 계속 누적될 수 있습니다.

예를 들어 로봇이 물체를 잡는 위치가 조금만 어긋나도 다음 순간의 상태는 시연 데이터에서 보던 장면과 달라집니다. 그러면 모델은 익숙하지 않은 상태에서 다시 동작을 예측해야 하고, 이 과정에서 오차가 더 커질 수 있습니다.

정밀 조작에서는 이런 문제가 특히 치명적입니다. 작은 위치 차이도 접촉 상태를 바꾸고, 접촉 상태가 바뀌면 이후의 동작 전체가 실패로 이어질 수 있기 때문입니다.

#### 1-2. ACT가 해결하려는 문제

ACT의 핵심 질문은 다음과 같습니다.

> 정밀 조작에서 한 동작씩 예측할 때 발생하는 누적 오차를 어떻게 줄일 수 있는가

ACT는 이 문제를 해결하기 위해 다음 한 동작만 예측하지 않습니다.

대신 현재 상태를 보고 앞으로 수행할 여러 동작을 하나의 묶음으로 예측합니다.

```
Copy
현재 관측 → 앞으로의 여러 동작
```

이렇게 하면 로봇은 매 순간 독립적으로 한 동작만 고르는 것이 아니라, 짧은 행동 계획 단위를 한 번에 예측하게 됩니다.

#### 1-3. ACT의 핵심 방향

ACT는 정밀 조작을 위한 모방학습 모델입니다.

핵심은 다음과 같습니다.

> ACT는 현재 관측을 바탕으로 다음 한 동작이 아니라, 앞으로 이어질 여러 동작의 흐름을 예측함으로써 정밀 조작에서 발생하는 누적 오차를 줄이고자 한 모델입니다.

## Ⅱ. 배경지식

### 1. Action Chunking의 개념

ACT를 이해하기 위해 가장 먼저 봐야 할 개념은 Action Chunking입니다.

Action Chunking은 로봇의 동작을 하나씩 따로 예측하지 않고, 앞으로 이어질 여러 동작을 하나의 묶음으로 예측하는 방식입니다.

기존 방식은 현재 상태를 보고 바로 다음 동작 하나만 예측합니다.

```
Copy
현재 로봇 상태와 카메라 이미지
→ 바로 다음 동작 1개 예측
```

예를 들어 컵 뚜껑을 여는 작업이라면, 기존 방식은 매 순간마다 다음 움직임을 하나씩 결정합니다.

```
Copy
컵에 조금 더 가까이 이동
→ 손을 조금 닫기
→ 손목을 조금 회전
→ 다시 손목을 조금 회전
```

반면 ACT는 현재 상태를 보고 앞으로 이어질 여러 동작을 한 번에 예측합니다.

```
Copy
현재 로봇 상태와 카메라 이미지
→ 앞으로 이어질 여러 동작 묶음 예측
```

예를 들어 다음과 같은 짧은 행동 흐름을 하나의 묶음으로 예측하는 방식입니다.

```
Copy
컵에 접근하기
→ 컵을 잡기
→ 손목을 회전하기
→ 뚜껑을 열기
```

여기서 중요한 점은 단순히 출력 개수가 많아졌다는 것이 아닙니다.

ACT는 로봇 행동을 한 순간의 동작이 아니라, 짧은 시간 동안 이어지는 행동 흐름으로 다룹니다.

이 방식의 장점은 모델이 매 순간 따로 판단하지 않고, 가까운 미래의 행동 흐름을 함께 고려할 수 있다는 점입니다.

논문에서는 이를 통해 작업의 유효 길이를 줄일 수 있다고 설명합니다.

유효 길이는 로봇이 연속적으로 정확한 판단을 유지해야 하는 시간적 길이를 의미합니다.

예를 들어 100개의 작은 동작으로 이루어진 작업을 매 순간 하나씩 예측해야 한다면, 모델은 100번의 판단을 연속으로 성공해야 합니다. 반면 여러 동작을 묶어서 예측하면, 전체 작업을 더 짧은 행동 단위들로 나누어 다룰 수 있습니다.

정리하면 Action Chunking은 다음과 같은 개념입니다.

> Action Chunking은 로봇의 다음 한 동작만 예측하는 대신, 앞으로 이어질 여러 동작을 하나의 행동 묶음으로 예측하는 방식입니다.

ACT의 핵심은 바로 이 지점에 있습니다.

로봇 행동을 한 동작 단위가 아니라, 짧은 행동 흐름 단위로 다시 정의했다는 것입니다.

## Ⅲ. 모델 구조

### 1. ACT의 입력과 출력 구조

ACT는 현재 시점의 정보를 입력으로 받아, 앞으로 이어질 여러 시점의 로봇 동작을 예측합니다.

여기서 입력은 크게 두 부분으로 이루어집니다.

![ACT 입력 관측 구성](https://static.wikidocs.net/images/page/366371/gh_311fd5f5e9c6.png)

- 

이미지 정보
 위쪽 카메라, 앞쪽 카메라, 왼쪽 손목 카메라, 오른쪽 손목 카메라에서 들어오는 4개의 RGB 이미지

- 

로봇 상태 정보
 현재 두 로봇 팔의 관절 위치

논문에서는 4개의 480×640 RGB 이미지와 두 팔의 관절 위치를 함께 사용합니다.

두 팔을 합치면 관절은 총 14개입니다.

출력은 다음 한 동작이 아니라, 앞으로의 여러 시점에서 로봇이 도달해야 할 관절 위치들입니다.

이를 쉽게 말하면, 출력은 다음과 같은 표에 가깝습니다.

```
Copy
미래 시점 1 : 관절1, 관절2, 관절3, ... 관절14의 목표 위치
미래 시점 2 : 관절1, 관절2, 관절3, ... 관절14의 목표 위치
미래 시점 3 : 관절1, 관절2, 관절3, ... 관절14의 목표 위치
...
미래 시점 k : 관절1, 관절2, 관절3, ... 관절14의 목표 위치
```

즉, ACT는 “바로 다음에 무엇을 할까”만 정하는 것이 아니라 앞으로 이어질 짧은 동작 흐름 전체를 한 번에 예측합니다.

![ACT 행동 묶음 출력 예시](https://static.wikidocs.net/images/page/366371/gh_fcde8df28fac.png)

중요한 점은 ACT가 이 동작을 토큰처럼 나누어 고르는 방식이 아니라, 각 관절의 목표 위치를 연속적인 수치값으로 직접 다룬다는 것입니다.

ACT는 “미리 정해진 동작 번호 중 하나를 선택하는 모델”이 아니라, 각 시점마다 로봇의 14개 관절이 어디에 있어야 하는지를 직접 예측하는 모델입니다.

학습할 때도 사람의 시연 데이터에서 얻은 joint 값을 그대로 사용합니다.

다만 이 값을 그대로 모델에 넣는 것이 아니라, 모델이 처리하기 쉬운 형태로 바꾼 뒤 사용합니다.

추론할 때도 마찬가지로, ACT는 동작 토큰을 예측하는 것이 아니라 앞으로의 연속적인 관절 위치 흐름을 직접 예측합니다.

하지만 action chunk를 예측한다고 해서 문제가 완전히 해결되는 것은 아닙니다.

만약 로봇이 로봇 상태 정보와 이미지 정보(observation)를 한 번 보고 그다음 k개의 action을 그대로 연속 실행해 버리면, 새로운 시각 정보를 중간에 반영하지 못해 움직임이 뚝뚝 끊기거나 환경 변화에 덜 민감해질 수 있습니다.

논문은 이를 보완하기 위해 Temporal Ensembling을 함께 사용합니다.

#### 1-1. 왜 Temporal Ensembling이 필요한가

ACT는 한 번 예측한 행동 묶음을 그대로 끝까지 실행하지 않습니다.

대신 매 시점마다 현재 관측을 다시 보고, 새로운 미래 행동 묶음을 계속 예측합니다.

즉, 로봇은 다음과 같이 작동합니다.

```
Copy
현재 시점 1에서 미래 행동 묶음 예측
현재 시점 2에서 다시 미래 행동 묶음 예측
현재 시점 3에서 다시 미래 행동 묶음 예측
...
```

이렇게 하면 로봇은 중간에 새로 들어오는 시각 정보를 계속 반영할 수 있습니다.

하지만 동시에 새로운 문제가 생깁니다.

서로 다른 시점에서 예측한 행동 묶음들이 시간상 서로 겹치기 때문에, 특정 시점에 대해 여러 개의 후보 행동이 생기는 것입니다.

#### 1-2. Temporal Ensembling은 어떻게 작동하는가

Temporal Ensembling은 서로 겹쳐서 예측된 행동들 중, 같은 시점에 해당하는 행동들만 모아 평균하는 방법입니다.

```
Copy
겹치는 여러 행동 묶음
→ 같은 시점에 해당하는 행동 후보들을 모음
→ 평균하여 최종 행동 결정
```

![Temporal Ensembling 구조](https://static.wikidocs.net/images/page/366371/gh_acf94132ab25.png)

즉, ACT는 다음 방식처럼 한 번 예측한 행동 묶음을 그대로 끝까지 실행하지 않습니다.

```
Copy
예측한 행동 묶음 하나를 그대로 끝까지 실행
```

대신 매 시점마다 새로운 행동 묶음을 다시 예측하고, 서로 겹치는 예측값들을 모아 최종 실행할 동작을 정합니다.

```
Copy
매 시점마다 새로운 행동 묶음을 예측
→ 겹치는 예측값들을 모음
→ 같은 시점의 행동들을 평균
→ 최종 동작으로 실행
```

이 과정을 통해 로봇은 새 관측을 계속 반영하면서도, 동작이 갑자기 흔들리지 않도록 만들 수 있습니다.

#### 1-3. 일반적인 smoothing과의 차이

여기서 중요한 점은 Temporal Ensembling이 단순한 smoothing과 다르다는 것입니다.

일반적인 smoothing은 보통 서로 인접한 시간의 행동을 섞습니다.

예를 들어 바로 이전 행동과 다음 행동을 평균내어 움직임을 부드럽게 만드는 방식입니다.

반면 ACT의 Temporal Ensembling은 서로 다른 시간의 행동을 아무렇게나 섞지 않습니다.

오직 같은 미래 시점에 대해 여러 번 예측된 행동들만 평균합니다.

즉, 평균의 대상은 다음과 같습니다.

```
Copy
서로 다른 시점에서 예측했지만,
실제로는 같은 실행 시점에 해당하는 행동들
```

이 방식은 행동을 부드럽게 만들면서도, 원래 의도와 다른 방향으로 값이 치우치는 문제를 줄이는 데 도움이 됩니다.

#### 1-4. Temporal Ensembling의 효과

논문에서는 Temporal Ensembling을 적용했을 때 ACT의 성능이 더 안정적으로 향상되었다고 보고합니다.

Ablation 결과에서 Temporal Ensembling을 사용하지 않았을 때 평균 성공률은 44.0%였고, Temporal Ensembling을 사용했을 때는 47.3%로 증가했습니다.

따라서

> Temporal Ensembling은 매 시점 새롭게 예측된 행동 묶음들 중 같은 실행 시점에 해당하는 행동을 평균하여, 새 관측을 반영하면서도 부드럽고 안정적인 로봇 동작을 만들기 위한 방법입니다.

정리하면 ACT의 입력과 출력은 다음과 같습니다.

- 입력: 현재 장면을 보여주는 4개의 카메라 이미지 + 현재 양팔의 관절 위치
- 출력: 앞으로 여러 시점에 걸쳐 로봇이 따라가야 할 양팔 관절 위치의 흐름

즉, ACT에서 다루는 시퀀스는 단어처럼 나열된 토큰 시퀀스가 아니라, 시간에 따라 이어지는 로봇 자세의 시퀀스라고 이해하는 것이 더 정확합니다.

이후에는 이러한 입력과 출력을 ACT가 실제로 어떤 구조로 처리하는지 살펴보겠습니다.

### 2. ACT의 전체 모델 구조와 CVAE

![ACT 전체 구조와 CVAE](https://static.wikidocs.net/images/page/366371/gh_18f10327d6a0.png)

ACT의 Transformer 기반 학습 구조를 이해하려면 먼저 CVAE에 대한 이해가 필요합니다.

> CVAE 는 VAE에서 확장된 조건부 생성 모델입니다. VAE는 데이터 안에 숨어 있는 변동성을 잠재변수로 표현하는 생성 모델이고, CVAE는 여기에 조건 정보를 추가해 특정 입력 조건에서 가능한 여러 출력을 생성하거나 학습할 수 있도록 만든 구조 입니다.

#### 2-1. 왜 CVAE가 필요한가

사람의 시연 데이터는 항상 하나의 정답처럼 깔끔하지 않습니다.

같은 물체를 같은 목표로 조작하더라도, 사람은 매번 조금씩 다른 경로를 사용할 수 있습니다. 예를 들어 공중에서 테이프를 건네주는 작업을 생각해보면, 시연마다 테이프를 건네주는 높이, 팔의 위치, 그리퍼의 자세가 조금씩 달라질 수 있습니다.

그렇다고 해서 이런 데이터들이 틀린 것은 아닙니다.

모두 작업을 성공시키는 유효한 방법일 수 있습니다.

즉, 같은 현재 상태에서도 앞으로 이어질 행동 흐름은 여러 가지가 될 수 있습니다.

```
Copy
같은 현재 상태
→ 가능한 행동 흐름 A
→ 가능한 행동 흐름 B
→ 가능한 행동 흐름 C
```

이런 상황에서 모델이 “정답은 하나뿐이다”라고 가정하고 학습하면, 여러 가능한 행동을 섞어 놓은 듯한 애매한 출력을 만들 수 있습니다.

하지만 정밀 조작에서는 이런 평균적인 동작이 오히려 실패로 이어질 수 있습니다.

ACT는 이 문제를 줄이기 위해 CVAE 구조를 사용합니다.

#### 2-2. CVAE에서 잠재변수 z의 역할

CVAE에서는 잠재변수 z라는 값을 사용합니다.

여기서 z는 쉽게 말해, 사람 시연 데이터에 들어 있는 행동 스타일이나 경로의 차이를 압축한 정보라고 볼 수 있습니다.

예를 들어 같은 작업이라도 어떤 데이터는 조금 더 높은 위치로 물체를 옮기고, 어떤 데이터는 더 낮은 경로로 옮길 수 있습니다.

또 어떤 데이터는 빠르게 접근하고, 어떤 데이터는 중간에 조금 멈춘 뒤 조심스럽게 접근할 수 있습니다.

z는 이런 차이를 모델 내부에서 표현하기 위한 변수입니다.

```
Copy
현재 상태는 비슷하지만
사람의 시연 경로가 조금씩 다름
→ 그 차이를 z에 압축
```

즉, z는 모델이 사람 시연의 다양한 행동 패턴을 학습할 수 있도록 도와주는 역할을 합니다.

#### 2-3. CVAE가 ACT에서 중요한 이유

논문에서도 CVAE의 중요성은 실험 결과로 확인됩니다.

정해진 규칙대로 생성된 시연 데이터에서는 CVAE를 제거해도 성능 차이가 거의 없었습니다.

하지만 사람 시연 데이터에서는 CVAE를 제거했을 때 성공률이 35.3%에서 2%로 크게 감소했습니다.

이 결과는 사람 시연 데이터가 단순하지 않다는 것을 보여줍니다.

사람의 시연에는 작은 흔들림, 속도 차이, 경로 차이, 여러 가능한 해결 방식이 함께 들어 있습니다.

따라서 CVAE는 단순히 모델을 복잡하게 만드는 요소가 아닙니다.

ACT가 사람 시연 데이터의 불규칙성과 다양한 행동 패턴을 학습하기 위해 필요한 구조입니다.

정리하면 다음과 같습니다.

> CVAE는 같은 현재 상태에서도 여러 타당한 행동 흐름이 존재할 수 있다는 점을 반영하기 위해 사용됩니다. ACT는 이를 통해 사람 시연 데이터의 변동성을 학습하고, 더 안정적인 행동 묶음을 예측할 수 있게 됩니다.

이제 다음으로는 ACT가 이 CVAE 구조를 어떻게 Transformer로 구현하는지를 살펴보겠습니다.

### 3. Transformer 기반 ACT 구조

앞서 ACT는 사람 시연 데이터의 다양한 행동 패턴을 다루기 위해 CVAE 구조를 사용한다고 설명했습니다.

이제 살펴볼 부분은 이 CVAE 구조가 실제 모델 안에서 어떻게 구현되는지입니다.

ACT의 전체 구조는 크게 두 부분으로 나눌 수 있습니다.

![ACT Transformer 구조 개요](https://static.wikidocs.net/images/page/366371/gh_b3ffa1e1155b.png)

그림을 기준으로 보면,

- 

왼쪽: CVAE encoder
 학습할 때만 사용되며, 사람 시연의 행동 흐름을 잠재변수 z로 압축합니다.

- 

오른쪽: Policy network
 실제로 카메라 이미지와 현재 관절 상태를 보고, 앞으로의 행동 묶음을 예측합니다.

여기서 중요한 점은 왼쪽과 오른쪽 모두 Transformer 구조를 사용하지만, 역할은 다르다는 것입니다.

왼쪽 encoder는 시연 데이터가 어떤 방식으로 움직였는지 요약하는 부분이고, 오른쪽 policy network는 현재 관측을 바탕으로 실제 행동을 예측하는 부분입니다.

여기서 왼쪽 encoder와 오른쪽 encoder는 이름은 같지만 역할이 다릅니다.

- 왼쪽 encoder는 demonstration의 스타일을 z로 압축
- 오른쪽 encoder는 현재 observation과 z를 통합해 policy가 사용할 표현 생성

즉, ACT는 하나의 단일 Transformer만 사용하는 구조라기보다, CVAE의 encoder와 policy를 각각 Transformer로 구현한 구조라고 이해하는 편이 더 정확합니다.

조금 단순화해서 보면, ACT는 두 부분으로 나눌 수 있습니다.

- 

CVAE encoder
 demonstration의 action sequence와 현재 joint 상태를 바탕으로 잠재변수 z의 분포를 추정하는 부분

- 

CVAE decoder (policy)
 현재 observation과 z를 바탕으로 미래의 action chunk를 예측하는 부분

#### 3-1. 왼쪽: 시연 행동을 z로 압축하는 CVAE encoder

![CVAE encoder 구조](https://static.wikidocs.net/images/page/366371/gh_1a9e9701b774.png)

그림의 왼쪽 부분은 CVAE의 encoder입니다.

이 encoder는 현재 joint 상태와 시연 데이터에서 가져온 action sequence를 입력으로 받아, 해당 데이터가 가진 움직임의 스타일을 잠재변수 z로 압축하는 역할을 합니다.

```
Copy
현재 관절 상태 + 실제 시연 행동 묶음
→ encoder
→ 잠재변수 z 생성
```

여기서 중요한 점은 ACT가 행동을 단어 토큰처럼 잘게 나누어 처리하지 않는다는 것입니다.

ACT에서 한 시점의 행동은 두 팔의 목표 관절 위치를 담은 14차원 관절 벡터입니다.

즉, 한 시점의 행동은 다음과 같이 이해할 수 있습니다.

```
Copy
한 시점의 행동
= 왼팔 관절 위치들 + 오른팔 관절 위치들
= 총 14개 관절 목표값
```

그리고 이런 14차원 관절 벡터들이 시간 순서대로 모이면, 하나의 행동 묶음이 됩니다.

```
Copy
미래 시점 1의 14개 관절 목표값
미래 시점 2의 14개 관절 목표값
미래 시점 3의 14개 관절 목표값
...
```

이 값들은 그대로 Transformer에 들어가는 것이 아니라, 먼저 선형층을 통해 Transformer가 처리할 수 있는 형태로 바뀝니다. 현재 관절 상태 역시 같은 방식으로 변환됩니다.

그다음 입력 앞에는 [CLS] 토큰이 붙습니다.

[CLS] 토큰은 전체 시퀀스 정보를 대표해서 모으기 위한 특별한 위치라고 이해하면 됩니다.

이후 현재 관절 상태와 행동 묶음에는 시간 순서를 알려주는 위치 정보가 더해지고, Transformer encoder로 들어갑니다.

```
Copy
[CLS] 토큰
+ 현재 관절 상태
+ 실제 행동 묶음
→ Transformer encoder
```

Transformer encoder는 이 전체 흐름을 읽고, [CLS] 위치에 모인 정보를 이용해 잠재변수 z의 평균과 분산을 예측합니다.

여기서 평균과 분산을 예측한다는 것은, z를 하나의 고정된 값으로 바로 정하는 것이 아니라 “이 시연은 대략 어떤 행동 스타일 범위에 속하는가”를 확률적인 형태로 표현한다는 의미입니다.

정리하면 왼쪽 CVAE encoder의 역할은 다음과 같습니다.

> 현재 관절 상태와 실제 시연 행동 묶음을 보고, 이 시연이 어떤 방식으로 움직였는지를 잠재변수 z로 압축하는 것

다만 이 부분은 학습할 때만 필요합니다.

실제로 로봇을 실행할 때는 미래의 정답 행동 묶음을 알 수 없기 때문에, 이 encoder를 사용할 수 없습니다.

따라서 실행 시에는 z를 새로 계산하지 않고, 기본값인 0으로 두고 policy network를 사용합니다.

즉, 학습할 때는 사람 시연의 다양한 행동 스타일을 배우기 위해 encoder를 사용하지만, 실제 실행할 때는 평균적인 스타일을 기준으로 행동 묶음을 예측합니다.

#### 3-2. 오른쪽: 현재 관측을 바탕으로 행동을 예측하는 policy network

![Policy network 구조](https://static.wikidocs.net/images/page/366371/gh_5e9d5e7cc15e.png)

그림의 오른쪽 부분은 실제 행동 묶음을 예측하는 policy network입니다.

이 부분에는 세 가지 정보가 들어갑니다.

```
Copy
4개 카메라 이미지
+ 현재 관절 상태
+ 잠재변수 z
```

이 정보들을 바탕으로 policy network는 앞으로 이어질 행동 묶음을 예측합니다.

```
Copy
현재 관측 정보
→ policy network
→ 미래 행동 묶음
```

즉, 오른쪽 policy network가 실제 ACT의 정책 역할을 합니다.

여기서 중요한 부분은 ACT가 단순히 이미지와 joint 값을 같이 쓴다는 사실보다, 서로 다른 형태의 입력을 같은 표현 공간으로 올린 뒤 Transformer가 통합한다는 점에 있습니다.

##### 3-2-1. 카메라 이미지는 어떻게 Transformer 입력이 되는가

ACT는 4개의 카메라 이미지를 그대로 Transformer에 넣지 않습니다.

이미지는 먼저 ResNet18을 거쳐, 행동 예측에 필요한 시각 특징으로 변환됩니다.

ResNet18은 이미지 인식에서 널리 사용되는 CNN 계열 모델입니다. CNN은 이미지 전체를 한 번에 숫자로 바꾸는 것이 아니라, 작은 영역을 차례로 살펴보면서 선, 모서리, 물체의 일부, 위치 관계 같은 시각적 패턴을 뽑아냅니다.

![ResNet18 시각 특징 추출기](https://static.wikidocs.net/images/page/366371/gh_900343e8217c.png)

ResNet18의 특징은 이름 그대로 18개의 층을 가진 ResNet 구조라는 점입니다. ResNet은 깊은 신경망을 더 안정적으로 학습하기 위해 잔차 연결을 사용합니다. 잔차 연결은 중간 층의 출력을 다음 층으로만 보내는 것이 아니라, 이전 입력을 뒤쪽 층에 함께 더해주는 구조입니다. 원 논문에서는 이러한 residual learning 구조가 깊은 네트워크를 더 쉽게 최적화하도록 돕는다고 설명합니다.

ACT에서 ResNet18의 역할은 이미지를 분류하는 것이 아닙니다.

여기서는 카메라 이미지에서 행동 예측에 필요한 시각 특징을 뽑아내는 시각 특징 추출기로 사용됩니다.

흐름은 다음과 같습니다.

```
Copy
카메라 이미지
→ ResNet18
→ 시각 특징
→ Transformer encoder
```

논문에서는 각 카메라 이미지가 480 × 640 × 3 크기로 들어갑니다.

여기서 480 × 640은 이미지의 세로와 가로 크기이고, 3은 RGB 색상 채널을 의미합니다.

이 이미지는 ResNet18을 거치면서 15 × 20 × 512 크기의 특징 지도로 바뀝니다. ACT 논문은 ResNet18 backbone이 480 × 640 × 3 RGB 이미지를 15 × 20 × 512 특징 지도로 변환한다고 설명합니다.

이 숫자는 다음처럼 이해하면 됩니다.

```
Copy
15 × 20
= 이미지를 작은 공간 구역 300개로 나눈 것

512
= 각 구역을 설명하는 시각 특징의 개수
```

즉, 원본 이미지를 픽셀 하나하나 그대로 보는 것이 아니라, 이미지를 300개의 작은 구역으로 요약하고 각 구역마다 “여기에 어떤 시각 정보가 있는지”를 512개의 숫자로 표현하는 것입니다.

이후 15 × 20개의 공간 구역은 한 줄로 펼쳐집니다.

```
Copy
15 × 20개의 구역
= 300개의 시각 특징
```

쉽게 말하면, 이미지 한 장이 300개의 시각 정보 조각으로 바뀌는 것입니다.

이 정보 조각들은 Transformer가 하나씩 읽을 수 있는 입력 단위가 됩니다.

또한 각 시각 특징에는 위치 정보가 함께 더해집니다.

이 위치 정보는 해당 특징이 이미지의 위쪽에서 온 것인지, 아래쪽에서 온 것인지, 왼쪽에서 온 것인지, 오른쪽에서 온 것인지를 알려주는 역할을 합니다.

따라서 ACT는 이미지 전체를 하나의 숫자 벡터로 뭉개버리는 것이 아니라, 이미지 안에서 어디에 무엇이 있는지를 어느 정도 유지한 채 Transformer에 전달합니다.

4개의 카메라 이미지에 이 과정을 모두 적용하면 다음과 같습니다.

```
Copy
카메라 1장
→ 300개의 시각 특징

카메라 4장
→ 300 × 4 = 1200개의 시각 특징
```

즉, ACT의 policy network는 4개의 카메라에서 나온 정보를 합쳐 총 1200개의 시각 특징을 Transformer에 전달합니다.

정리하면 다음과 같습니다.

```
Copy
4개 카메라 이미지
→ ResNet18
→ 각 이미지당 300개의 시각 특징
→ 총 1200개의 시각 특징
→ Transformer encoder로 전달
```

ACT에서 ResNet18은 “최종 행동을 결정하는 모델”이라기보다, 카메라 이미지를 Transformer가 읽을 수 있는 시각 특징으로 바꿔주는 앞단의 이미지 처리기라고 이해하면 됩니다.

##### 3-2-2. 관절 상태와 z는 어떻게 함께 들어가는가

Transformer encoder에는 이미지에서 뽑은 시각 특징만 들어가는 것이 아닙니다.

ACT는 현재 로봇의 관절 상태와 잠재변수 z도 함께 사용합니다.

여기서 두 정보는 서로 다른 역할을 합니다.

```
Copy
현재 관절 상태
→ 로봇 팔이 지금 어떤 자세인지 알려줌

잠재변수 z
→ 시연 행동의 스타일이나 변동성을 담음
```

현재 관절 상태는 두 팔의 관절 위치를 담은 14개의 숫자로 표현됩니다.

즉, 로봇 양팔의 현재 자세를 나타내는 정보입니다.

하지만 앞에서 본 이미지 특징은 각 시각 정보 조각이 512차원 표현으로 바뀌어 있었습니다.

따라서 관절 상태도 이미지 특징과 함께 Transformer가 처리할 수 있도록 같은 크기의 표현으로 변환해야 합니다.

이를 위해 ACT는 현재 관절 상태를 선형층을 통해 512차원으로 바꿉니다.

```
Copy
현재 관절 상태
14개 숫자
→ 선형층
→ 512차원 관절 표현
```

여기서 선형층은 입력 숫자들을 조합해 새로운 크기의 표현으로 바꿔주는 간단한 신경망 층입니다.

쉽게 말하면, 14개의 관절 숫자를 Transformer가 읽을 수 있는 512개의 특징값으로 번역하는 과정입니다.

이 과정은 언뜻 보면 ACT도 action을 토큰화해서 사용하는 것처럼 보일 수 있습니다. 하지만 ACT는 관절값을 이산적인 token ID로 바꾸는 것이 아니라, Transformer 입력으로 사용하기 위해 연속적인 관절값을 임베딩하는 것입니다. 즉, ACT는 RT-1, RT-2, OpenVLA처럼 action 값을 여러 구간으로 나누어 token으로 예측하는 모델이 아니며, 최종 출력도 연속적인 관절 목표값입니다.

잠재변수 z도 같은 방식으로 처리됩니다.

z도 그대로 Transformer에 넣는 것이 아니라, 선형층을 거쳐 512차원 표현으로 바뀝니다.

```
Copy
잠재변수 z
→ 선형층
→ 512차원 z 표현
```

이제 Transformer encoder에 들어갈 세 종류의 정보가 모두 같은 형식으로 맞춰집니다.

```
Copy
시각 특징
→ 각 조각이 512차원

관절 상태
→ 512차원 관절 표현 1개

잠재변수 z
→ 512차원 z 표현 1개
```

앞에서 4개의 카메라 이미지는 총 1200개의 시각 특징으로 바뀐다고 했습니다.

여기에 관절 상태 표현 1개와 z 표현 1개가 추가됩니다.

따라서 Transformer encoder의 입력은 다음과 같이 구성됩니다.

```
Copy
1200개의 시각 특징
+ 1개의 관절 상태 표현
+ 1개의 z 표현
= 총 1202개의 입력 조각
```

각 입력 조각은 모두 512차원입니다.

즉, Transformer encoder는 총 1202개의 정보 조각을 읽고, 각 조각은 512개의 숫자로 표현됩니다.

```
Copy
Transformer encoder 입력
= 1202개의 정보 조각
= 각 조각은 512차원 표현
```

이 구조에서 중요한 점은 ACT가 서로 다른 종류의 정보를 따로 처리한 뒤 마지막에 단순히 붙이는 것이 아니라는 점입니다.

시각 정보, 현재 로봇 자세, 시연 스타일 정보를 모두 같은 표현 크기로 맞춘 뒤, Transformer encoder 안에서 서로 관계를 보게 만듭니다.

즉, Transformer encoder는 다음과 같은 질문을 함께 고려할 수 있습니다.

```
Copy
물체는 어느 카메라의 어느 위치에 보이는가?
로봇 팔은 현재 어떤 자세인가?
이 시연 스타일에서는 다음 행동을 어떻게 이어가야 하는가?
```

#### 3-3. Transformer decoder는 미래 행동 묶음을 예측한다

Transformer encoder가 현재 상황을 통합하면, 그다음에는 Transformer decoder가 미래 행동 묶음을 예측합니다.

![Transformer decoder 구조](https://static.wikidocs.net/images/page/366371/gh_b56ff8cd6850.png)

여기서 decoder는 “앞으로 몇 번째 시점의 행동을 예측할 것인지”에 해당하는 입력을 받습니다.

이 입력은 실제 이미지나 관절값이 아니라, 미래 시점의 순서를 알려주는 고정된 위치 표현입니다.

쉽게 말하면 decoder는 다음 질문들을 순서대로 던지는 역할을 합니다.

```
Copy
미래 시점 1에서는 어떤 관절 위치가 필요한가?
미래 시점 2에서는 어떤 관절 위치가 필요한가?
미래 시점 3에서는 어떤 관절 위치가 필요한가?
...
미래 시점 k에서는 어떤 관절 위치가 필요한가?
```

decoder는 encoder가 만든 현재 상황 표현을 참고하면서, 각 미래 시점에 해당하는 행동 표현을 만듭니다.

```
Copy
Transformer encoder 출력
+ 미래 시점별 위치 정보
→ Transformer decoder
→ 미래 시점별 행동 표현
```

그다음 마지막에는 MLP를 거쳐 실제 로봇이 사용할 수 있는 관절 목표값으로 변환됩니다.

![MLP 출력 헤드](https://static.wikidocs.net/images/page/366371/gh_82fae2ff439b.png)

MLP는 여러 개의 선형층과 활성화 함수로 이루어진 가장 기본적인 신경망 구조입니다.

여기서는 복잡한 판단을 새로 하는 부분이라기보다, Transformer decoder가 만든 미래 시점별 표현을 실제 관절 목표값의 형태로 바꿔주는 출력 변환기 역할을 합니다.

```
Copy
미래 시점별 행동 표현
→ MLP
→ 미래 시점별 14개 관절 목표값
```

즉, 최종 출력은 다음과 같습니다.

```
Copy
미래 시점 1 : 14개 관절 목표값
미래 시점 2 : 14개 관절 목표값
미래 시점 3 : 14개 관절 목표값
...
미래 시점 k : 14개 관절 목표값
```

여기서 주의할 점은 ACT가 동작을 토큰 번호처럼 고르는 모델이 아니라는 것입니다.

최종 출력은 각 관절이 어디로 움직여야 하는지를 나타내는 연속적인 수치값입니다.

#### 3-4. 오른쪽 policy network의 전체 흐름

그림의 오른쪽 policy network를 기준으로 전체 흐름을 다시 정리하면 다음과 같습니다.

```
Copy
4개 카메라 이미지
→ ResNet18
→ 1200개의 시각 특징

현재 관절 상태
→ 선형층
→ 1개의 관절 상태 특징

잠재변수 z
→ 선형층
→ 1개의 스타일 특징

1200개 시각 특징
+ 1개 관절 상태 특징
+ 1개 z 특징
→ Transformer encoder
→ 현재 상황에 대한 통합 표현

Transformer decoder
→ 미래 k개 시점의 행동 표현

MLP
→ 미래 k개 시점의 14개 관절 목표값
```

즉, ACT의 policy network는 단순히 이미지를 보고 다음 한 동작을 출력하는 구조가 아닙니다.

여러 카메라 시점의 시각 정보, 현재 로봇의 관절 상태, 그리고 z를 함께 통합한 뒤, 앞으로 이어질 연속적인 행동 묶음 전체를 예측하는 구조입니다.

정리하면 다음과 같습니다.

> ACT의 Transformer 구조는 여러 카메라 이미지에서 뽑은 시각 특징, 현재 관절 상태, 잠재변수 z를 하나의 시퀀스로 합쳐 현재 상황을 이해하고, 이를 바탕으로 미래의 관절 움직임 묶음을 예측하는 구조입니다.

### 4. ACT의 학습과 추론 방식

ACT는 학습할 때 사람의 시연 데이터에서 현재 관측 정보와 그 뒤에 이어지는 행동 묶음을 함께 가져옵니다.

즉, 모델은 다음과 같은 데이터를 보고 학습합니다.

```
Copy
현재 관측 정보
+ 실제 사람이 수행한 미래 행동 묶음
```

여기서 현재 관측 정보에는 카메라 이미지와 현재 로봇 관절 상태가 포함됩니다.

미래 행동 묶음은 사람이 실제로 수행한 여러 시점의 관절 목표값입니다.

ACT의 학습 과정은 크게 두 단계로 볼 수 있습니다.

```
Copy
1단계:
현재 관절 상태
+ 실제 행동 묶음
→ CVAE encoder
→ 잠재변수 z

2단계:
카메라 이미지
+ 현재 관절 상태
+ z
→ policy decoder
→ 미래 행동 묶음 예측
```

즉, encoder는 시연 행동의 특징을 z로 압축하고, decoder는 현재 관측과 z를 바탕으로 실제 시연 행동 묶음을 다시 예측하도록 학습됩니다.

#### 4-1. ACT는 무엇을 잘하도록 학습되는가

ACT의 학습 목표는 간단히 말하면 다음과 같습니다.

> 현재 상황을 보고, 사람이 실제로 수행한 미래 행동 묶음과 비슷한 행동을 예측하도록 학습하는 것

이를 위해 논문에서의 학습 손실은 크게 두 부분으로 이해할 수 있습니다.

```
Copy
전체 손실
= 복원 손실
+ β × 정규화 손실
```

여기서 두 손실은 각각 다른 역할을 합니다.

- 

복원 손실
 예측한 행동 묶음이 실제 시연 행동 묶음과 얼마나 가까운지 보는 항

- 

정규화 손실
 잠재변수 z가 너무 제멋대로 흩어지지 않도록 잡아주는 항

β는 정규화 손실을 얼마나 강하게 반영할지 조절하는 값입니다.

즉, ACT는 단순히 행동을 잘 맞히는 것뿐 아니라, z가 안정적인 잠재공간 안에서 표현되도록 함께 학습합니다.

#### 4-2. 복원 손실: 예측한 행동이 실제 시연과 얼마나 가까운가

복원 손실은 가장 직관적인 손실입니다.

모델이 예측한 미래 행동 묶음과 사람이 실제로 수행한 행동 묶음을 비교합니다.

```
Copy
예측한 미래 행동 묶음
↔ 실제 시연 행동 묶음
```

이 손실이 작아질수록 모델은 현재 상황에서 사람이 실제로 했던 움직임과 더 비슷한 행동을 예측하게 됩니다.

예를 들어 사람이 컵을 잡고 돌리는 행동을 시연했다면, ACT는 그 시연에서 나타난 관절 움직임의 흐름을 비슷하게 복원하도록 학습됩니다.

논문을 읽을 때 이 부분은 조금 헷갈릴 수 있습니다.

알고리즘 표기에서는 복원 손실이 MSE처럼 적혀 있지만, 구현 설명에서는 실제로 L1 loss를 사용했다고 설명합니다.

쉽게 말하면 두 손실은 다음과 같이 다릅니다.

```
Copy
L2 loss:
예측값과 정답의 차이를 제곱해서 계산

L1 loss:
예측값과 정답의 절대값 차이로 계산
```

L2 loss는 큰 오차에 더 민감하게 반응합니다.

반면 L1 loss는 각 관절 목표값의 절대적인 차이를 기준으로 비교합니다.

ACT에서는 실제 구현에서 L1 loss를 사용한 것이 더 정밀한 행동 시퀀스 예측에 유리했다고 설명합니다.

> ACT의 복원 손실은 예측한 행동 묶음이 실제 시연 행동 묶음과 얼마나 가까운지를 보는 항입니다. 알고리즘 표기에서는 MSE처럼 제시되지만, 구현 설명에서는 L1 loss를 사용했다고 정리할 수 있습니다.

#### 4-3. 정규화 손실: z가 너무 제멋대로 되지 않게 하기

정규화 손실은 잠재변수 z를 안정적으로 만들기 위한 항입니다.

앞에서 설명했듯이 z는 사람 시연의 행동 스타일이나 경로 차이를 담는 값입니다.

하지만 제약이 없다면 encoder는 각 시연마다 너무 복잡하고 제각각인 z를 만들 수 있습니다.

이 경우 모델은 사람 시연의 일반적인 패턴을 배우기보다, 각각의 시연을 통째로 외우는 방향으로 갈 수 있습니다.

그래서 ACT는 encoder가 만든 z의 분포가 미리 정한 기본 분포에서 너무 멀어지지 않도록 제한합니다.

보통 이 기본 분포는 평균이 0이고 분산이 1인 가우시안 분포로 둡니다.

```
Copy
z가 너무 멀리 흩어지지 않도록 제한
→ 안정적인 잠재공간 형성
→ 시연 스타일을 과도하게 외우지 않도록 유도
```

즉, 정규화 손실은 z가 시연의 차이를 담되, 너무 불안정하거나 과적합된 표현이 되지 않게 만드는 역할을 합니다.

정리하면 다음과 같습니다.

> 정규화 손실은 z가 사람 시연의 다양성을 표현하되, 너무 제멋대로 흩어지지 않도록 잡아주는 항입니다.

#### 4-4. β는 무엇을 조절하는가

전체 손실에서 β는 정규화 손실의 비중을 조절합니다.

```
Copy
전체 손실
= 복원 손실
+ β × 정규화 손실
```

β가 너무 작으면 모델은 z를 자유롭게 사용하면서 시연 데이터를 외우는 방향으로 갈 수 있습니다.

반대로 β가 너무 크면 z가 너무 강하게 제한되어 시연 데이터의 다양한 행동 패턴을 충분히 담지 못할 수 있습니다.

따라서 β는 다음 두 목표 사이의 균형을 맞추는 값입니다.

```
Copy
행동을 정확히 복원하기
↔
z를 안정적인 잠재공간 안에 두기
```

즉, ACT는 행동 묶음을 잘 맞히는 것과 사람 시연의 다양성을 안정적으로 표현하는 것 사이에서 균형을 잡도록 학습됩니다.

#### 4-5. 추론할 때는 무엇이 달라지는가

학습할 때는 실제 시연 행동 묶음이 있기 때문에 encoder가 z를 만들 수 있습니다.

하지만 실제 로봇을 실행할 때는 미래의 정답 행동 묶음을 알 수 없습니다.

따라서 추론할 때는 CVAE encoder를 사용하지 않습니다.

대신 z를 기본값인 0으로 두고 policy decoder만 사용합니다.

```
Copy
추론할 때:

카메라 이미지
+ 현재 관절 상태
+ z = 0
→ policy decoder
→ 미래 행동 묶음 예측
```

즉, 학습할 때는 사람 시연의 다양한 행동 스타일을 배우기 위해 z를 사용하지만, 실제 실행할 때는 평균적인 스타일을 기준으로 행동 묶음을 예측합니다.

이때 정책은 무작위로 여러 행동을 샘플링하는 방식이 아니라, 같은 입력이 들어오면 같은 행동 묶음을 출력하는 결정적인 방식으로 동작합니다.

#### 4-6. 이 장의 핵심 정리

ACT의 학습과 추론 방식은 다음처럼 정리할 수 있습니다.

```
Copy
학습할 때:
실제 시연 행동 묶음을 이용해 z를 만들고,
현재 관측과 z를 바탕으로 행동 묶음을 복원하도록 학습한다.

추론할 때:
정답 행동 묶음이 없으므로 encoder는 사용하지 않고,
z를 0으로 둔 채 현재 관측만으로 행동 묶음을 예측한다.
```

결국 ACT의 학습 목표는 다음 한 문장으로 정리할 수 있습니다.

> ACT는 사람의 시연 행동 묶음을 잘 복원하도록 학습하면서, 동시에 잠재변수 z가 안정적인 범위 안에서 사람 시연의 다양한 행동 패턴을 표현하도록 학습됩니다.

## Ⅳ. 결과

### 1. ACT 실험 결과

ACT 논문은 제안한 방법이 실제 정밀 조작에서 효과적인지 확인하기 위해 시뮬레이션 과제와 실제 로봇 과제를 모두 평가했습니다.

이 장에서 볼 핵심 질문은 세 가지입니다.

```
Copy
1. ACT는 기존 imitation learning 방법보다 실제로 더 잘 동작하는가?

2. 성능 향상은 action chunking에서 비롯된 것인가?

3. Temporal Ensembling과 CVAE는 각각 어떤 역할을 하는가?
```

ACT의 실험 결과는 단순히 “Transformer를 사용해서 성능이 좋아졌다”는 방향으로 해석하기 어렵습니다. 논문에서 확인되는 핵심은 action chunking, temporal ensembling, CVAE가 각각 다른 문제를 해결하며 함께 작동했다는 점입니다.

#### 1-1. 실제 로봇 과제에서의 성능

논문은 ACT를 실제 로봇 환경의 정밀 양팔 조작 과제에서 평가했습니다. 과제들은 단순한 pick-and-place가 아니라, 물체를 고정하고, 밀고, 끼우고, 잡은 상태에서 다른 팔과 협응해야 하는 작업들입니다.

ACT의 실제 로봇 과제 최종 성공률은 다음과 같습니다.

과제ACT 최종 성공률

Slide Ziploc88%

Slot Battery96%

Open Cup84%

Thread Velcro20%

Prep Tape64%

Put On Shoe92%

Slide Ziploc과 Slot Battery에서는 ACT가 각각 88%, 96%의 최종 성공률을 보였고, Open Cup, Thread Velcro, Prep Tape, Put On Shoe에서는 각각 84%, 20%, 64%, 92%를 기록했습니다. 기존 방법들은 여러 과제에서 후반 단계까지 진행하지 못하거나 최종 성공률이 매우 낮았습니다.

여기서 눈에 띄는 점은 Thread Velcro의 성공률이 20%로 낮다는 것입니다. 논문에서는 검은색 벨크로 타이가 배경과 잘 구분되지 않고, 이미지에서 차지하는 면적도 작아 위치를 정확히 판단하기 어려웠다고 분석합니다. 이 결과는 ACT가 강한 성능을 보였더라도, 작은 물체와 낮은 시각 대비가 결합된 과제에서는 여전히 한계가 있음을 보여줍니다.

#### 1-2. 기존 방법과의 비교에서 보이는 차이

논문은 ACT를 기존 imitation learning 방법들과 비교했습니다.

비교 대상에는 다음과 같은 방법들이 포함됩니다.

```
Copy
BC-ConvMLP
이미지를 CNN으로 처리한 뒤, 현재 관절 상태와 함께 다음 행동을 예측하는 기본적인 behavioral cloning 방식

BeT
Transformer를 사용하지만, action chunking 없이 observation history를 바탕으로 한 step action을 예측하는 방식

RT-1
Transformer 기반 정책이지만, action을 이산적인 구간으로 나누어 예측하는 방식

VINN
현재 observation과 비슷한 demonstration을 찾아 해당 action을 사용하는 nearest-neighbor 기반 방식
```

비교 결과에서 ACT는 시뮬레이션 과제와 실제 로봇 과제 모두에서 가장 높은 성공률을 보였습니다. 특히 Slide Ziploc과 Slot Battery에서는 ACT가 높은 최종 성공률을 기록한 반면, 다른 방법들은 대부분 첫 단계 이후로 안정적으로 진행하지 못했습니다. 논문은 기존 방법들의 성능 저하를 compounding error와 non-Markovian behavior의 영향으로 해석합니다.

여기서 중요한 점은 기존 방법들이 “처음부터 아무것도 못 한다”는 것이 아닙니다. 일부 방법은 초반 동작에서는 어느 정도 진전을 보입니다. 하지만 시간이 길어지고 정밀한 후반 단계로 넘어갈수록 작은 오차가 누적되면서 전체 작업이 무너집니다.

ACT는 이 지점을 action chunking으로 줄였습니다. 다음 한 동작만 맞히는 대신, 짧은 미래 행동 흐름을 함께 예측하면서 전체 과제를 더 안정적인 단위로 다룬 것입니다.

#### 1-3. Action Chunking의 효과

ACT의 가장 중요한 변화는 예측 단위를 바꾼 것입니다.

기존 방식은 현재 상태를 보고 다음 한 동작만 예측합니다.

```
Copy
현재 상태
→ 다음 한 동작 예측
```

ACT는 현재 상태를 보고 앞으로 이어질 여러 시점의 행동 묶음을 예측합니다.

```
Copy
현재 상태
→ 미래 행동 묶음 예측
```

저자들은 action chunking의 효과를 확인하기 위해 chunk size k를 바꿔가며 실험했습니다. 여기서 k=1은 action chunking이 없는 경우로, 다음 한 동작만 예측하는 방식에 가깝습니다. 반대로 k가 커질수록 한 번에 더 긴 행동 흐름을 예측합니다.

실험 결과, Temporal Ensembling을 제외하고 action chunking만 보았을 때 ACT의 평균 성공률은 k=1에서 1%였지만, k=100에서는 44%까지 증가했습니다. 이후 k=200, k=400에서는 성능이 조금 낮아졌습니다. 너무 긴 행동 묶음은 새로운 관측 정보를 반영하기 어려워져 open-loop 제어에 가까워지기 때문입니다.

Action chunking의 효과는 이 결과에서 가장 직접적으로 드러납니다.

> 한 step씩 계속 예측하면 오차가 쉽게 누적되지만, 적절한 길이의 행동 묶음을 예측하면 작업의 유효 길이가 줄어들고 성능이 크게 향상됩니다.

이 결과는 ACT의 성능 향상이 단순히 Transformer 구조에서만 나온 것이 아니라, 행동을 묶어서 예측하는 방식 자체가 imitation learning에 유효했다는 점을 보여줍니다.

#### 1-4. Temporal Ensembling의 효과

Action chunking만 사용하면 또 다른 문제가 생길 수 있습니다.

한 번 관측한 뒤 여러 행동을 그대로 실행하면, 중간에 새로 들어오는 시각 정보를 충분히 반영하지 못할 수 있습니다.

ACT는 이 문제를 줄이기 위해 매 시점마다 새로운 행동 묶음을 다시 예측합니다. 그러면 서로 다른 시점에서 예측한 행동 묶음들이 시간상 겹치게 되고, 같은 실행 시점에 대해 여러 후보 행동이 생깁니다.

Temporal Ensembling은 이 후보 행동들을 가중 평균해 최종 실행할 행동을 정합니다.

```
Copy
여러 시점에서 예측된 행동 묶음
→ 같은 실행 시점에 해당하는 후보 행동들을 모음
→ 가중 평균
→ 최종 행동 실행
```

실험에서 Temporal Ensembling은 ACT의 평균 성공률을 44%에서 47.3%로 높였습니다. BC-ConvMLP도 25%에서 29%로 향상되었지만, VINN은 37%에서 17%로 낮아졌습니다. 이 결과는 Temporal Ensembling이 특히 parametric model의 예측 오차를 부드럽게 줄이는 데 도움이 된다는 해석을 뒷받침합니다.

Temporal Ensembling은 성능을 크게 뒤집는 장치라기보다, action chunking으로 예측된 행동들을 실제 로봇 제어에서 더 부드럽고 안정적으로 사용하게 해주는 보완 장치에 가깝습니다.

#### 1-5. CVAE의 효과

ACT는 사람 시연 데이터를 다루기 위해 CVAE 구조를 사용합니다.

사람의 demonstration은 항상 하나의 정답 경로처럼 깔끔하지 않습니다. 같은 과제를 수행하더라도 사람은 매번 조금씩 다른 높이, 속도, 경로로 움직일 수 있습니다.

이런 데이터에서 모델이 여러 시연을 하나의 평균적인 정답으로만 배우면, 실제로는 어떤 시연 경로도 제대로 따르지 못하는 애매한 행동을 만들 수 있습니다.

CVAE의 효과는 ablation 결과에서 분명하게 나타납니다.

데이터 종류CVAE 사용CVAE 제거

Scripted Data59%58%

Human Data35.3%2%

Scripted data에서는 CVAE를 제거해도 성능 차이가 거의 없었습니다. 반면 human data에서는 CVAE를 제거했을 때 성공률이 35.3%에서 2%로 크게 감소했습니다. 이 결과는 CVAE가 사람 시연 데이터의 불규칙성과 다양한 행동 패턴을 다루는 데 핵심적인 역할을 한다는 점을 보여줍니다.

CVAE의 의미는 단순히 모델을 더 복잡하게 만든 데 있지 않습니다.

사람이 만든 시연 데이터 안에 여러 가능한 행동 흐름이 존재한다는 점을 모델이 다룰 수 있게 만든 것이 핵심입니다.

#### 1-6. 실험 결과로 본 ACT의 의미

실험 결과를 종합하면, ACT의 성능은 하나의 요소로만 설명되지 않습니다.

ACT는 정밀 조작에서 imitation learning이 무너지는 원인을 세 가지로 나누어 다룹니다.

```
Copy
오차가 누적되는 문제
→ Action Chunking

행동 묶음을 그대로 실행할 때 움직임이 끊기는 문제
→ Temporal Ensembling

사람 시연 데이터가 불규칙하고 여러 경로를 가질 수 있는 문제
→ CVAE
```

이 구조에서 ACT는 단순한 Transformer policy가 아닙니다.

Transformer는 여러 입력 정보를 통합하고 미래 행동 시퀀스를 생성하는 뼈대 역할을 하지만, 성능 향상의 중심에는 action chunking, temporal ensembling, CVAE가 함께 있습니다.

ACT의 실험 결과가 보여주는 핵심은 다음과 같습니다.

> 정밀 로봇 조작에서는 다음 한 동작을 잘 맞히는 것만으로는 부족합니다. 짧은 미래 행동 흐름을 함께 예측하고, 그 예측을 매 시점 부드럽게 통합하며, 사람 시연 데이터의 다양성까지 다룰 수 있어야 합니다.

이 점에서 ACT는 imitation learning의 예측 단위를 single-step action에서 multi-step action chunk로 확장한 대표적인 사례라고 볼 수 있습니다.

## Ⅵ. 정리

### 1. 정리

ACT는 현재 관측을 보고 다음 한 동작만 예측하는 정책이 아닙니다.

여러 카메라 이미지와 현재 로봇 관절 상태를 입력으로 받아, 앞으로 이어질 짧은 행동 흐름 전체를 예측하는 모방학습 정책입니다.

전체 흐름은 다음과 같이 정리할 수 있습니다.

```
Copy
현재 카메라 이미지와 로봇 관절 상태를 입력으로 받음
→ 미래 행동 묶음을 예측함
→ 겹쳐 예측된 행동들을 Temporal Ensembling으로 부드럽게 합침
→ 최종 관절 목표값을 로봇이 실행함
```

ACT의 핵심은 Transformer를 사용했다는 사실 하나에 있지 않습니다.

더 중요한 변화는 로봇 행동을 한 동작 단위가 아니라, 짧은 행동 묶음 단위로 예측하도록 문제를 다시 정의했다는 점입니다.

이 변화는 정밀 조작에서 특히 중요합니다.

배터리를 슬롯에 끼우거나, 컵을 열거나, 테이프를 건네받아 붙이는 작업에서는 작은 오차가 다음 상태를 바꾸고, 그 오차가 다시 다음 예측을 어렵게 만듭니다. ACT는 action chunking을 통해 이러한 누적 오차 문제를 줄이고자 했습니다.

또한 ACT는 action chunking만 사용하지 않았습니다.

```
Copy
Action Chunking
→ 다음 한 동작이 아니라 미래 행동 흐름을 예측

Temporal Ensembling
→ 여러 번 겹쳐 예측된 행동을 부드럽게 합침

CVAE
→ 사람 시연 데이터의 다양한 행동 패턴을 학습

Transformer
→ 이미지, 관절 상태, z를 통합해 행동 묶음을 생성
```

이 구조를 통해 ACT는 저비용 양팔 로봇에서도 정밀한 조작 과제를 학습할 수 있음을 보여주었습니다.

논문 실험에서도 ACT는 여러 실제 로봇 과제에서 기존 모방학습 방법보다 높은 성공률을 보였습니다.

마지막으로 ACT를 한 문장으로 정리하면 다음과 같습니다.

> ACT는 정밀 조작에서 발생하는 누적 오차와 사람 시연 데이터의 다양성을 다루기 위해, 현재 관측으로부터 미래의 관절 행동 묶음을 예측하도록 설계된 Transformer 기반 모방학습 정책입니다.

이 관점에서 ACT는 이후 VLA 모델을 이해하는 데도 중요한 출발점이 됩니다.

OpenVLA 같은 모델은 언어와 이미지를 함께 사용해 action을 token 형태로 예측하지만, ACT는 그보다 앞서 로봇 행동을 시간적으로 이어진 action sequence로 다루는 것이 왜 중요한지를 보여준 모델이라고 볼 수 있습니다.
