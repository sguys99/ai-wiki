# GBrain — 오픈소스 개인 지식 베이스

> GeekNews(news.hada.io) 게시글. 작성자 xguru, 53P. 원문 링크: https://github.com/garrytan/gbrain
> WebFetch 수집(2026-07-05).

GBrain은 YC CEO Garry Tan이 개발한 개인 지식 관리 도구다. "분산된 마크다운 파일들을 Postgres 기반 지식 베이스로 통합"하며, 벡터와 키워드 검색을 결합한 하이브리드 검색을 제공한다.

## 핵심 기능

- Claude Haiku를 활용한 다중 쿼리 확장
- 7개 AI 에이전트 스킬 내장
- MCP 서버 20개 도구 제공
- 3단계 청킹 전략 지원
- Obsidian, Notion, Logseq 등에서 마이그레이션 지원

## 기술 스택

TypeScript, MIT 라이선스.

## v0.2.0 업데이트

git 기반 증분 동기화, Supabase Storage 파일 관리, 설치 스킬 추가.
