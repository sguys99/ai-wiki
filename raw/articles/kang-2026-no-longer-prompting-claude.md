## 본문 요약 (fetched summary)

프롬프트 엔지니어링에서 루프 엔지니어링으로의 진화를 다룬 글. 핵심 논지:

- Anthropic의 Boris Cherny는 초점이 "Claude를 프롬프팅하는 것"에서 "Claude를 프롬프팅하기 위한 루프를 설계하는 것"으로 옮겨갔다고 언급했다.
- 2026년 6월: "Loop Engineering"이 개념으로 등장했다.
- **진화 타임라인:** Prompt → Context → Harness → Loop (약 4년에 걸친 최적화 단위의 이동)

### 네 가지 엔지니어링 단계 (Four Engineering Stages)

1. **Prompt Engineering**: 단일 지시(single instruction) 최적화
2. **Context Engineering (2025)**: 프롬프트 바깥의 토큰을 최적화하는 Anthropic 개념
3. **Harness Engineering (2026, Feb)**: 실행 환경(execution environment)을 설계하자는 Mitchell Hashimoto의 제안
4. **Loop Engineering (June 7, 2026)**: 오케스트레이션 레이어를 가리키는 Addy Osmani의 용어

### 다섯 가지 루프 구성 요소 (Five Loop Components)

- Automations, Worktrees, Skills, Sub-agents, Connectors, + External State

### 세 가지 리스크 (Three Risks Identified)

- Validation debt (검증 부채)
- Understanding debt (이해 부채)
- Cognitive resistance (인지적 저항)
