# 그래프 페이지 시각 방향

작성일 2026-11-16. `docs/graph-design-plan.md` Phase 1 첫 항목의 산출물이다. 시안 A ~ E는 모두 이 문서와 `shared/` 를 따른다. 값은 `shared/mock-base.css` 토큰이 정본이고, 이 문서는 그 토큰을 언제 어떻게 쓰는지 정한다.

## 1. 방향 한 줄

**성도 판화.** 그래프 자체가 화면의 주인공이고, 나머지는 그 위에 얹힌 관측 기구의 유리판처럼 조용하다. 대담함은 한 곳, 캔버스에만 쓴다. 칩, 패널, 범례는 사이트의 기존 Constellation 크롬과 같은 hairline, 같은 반경, 같은 글꼴을 쓰고 장식을 더하지 않는다.

지켜야 할 것은 세 가지다.

- 별 이름을 성도에 적듯 라벨은 노드 오른쪽 위에 작게 붙는다. 노드보다 라벨이 먼저 눈에 들어오면 실패다.
- 밝기가 곧 중요도다. 허브는 크고 밝고, 잎 노드는 작고 어둡다. 색은 카테고리만 말한다.
- 움직임은 사용자가 일으킨 것에만 답한다. 첫 화면의 한 번의 등장 연출 외에 저절로 움직이는 것은 없다.

피할 것: 카드 격자, 그라데이션 배경, 노드마다 다른 아이콘, 대문자 라벨, 패널 안의 큰 숫자 통계 타일.

## 2. 타이포

글꼴은 사이트와 같은 세 가지다. 시안에서는 CDN으로 싣는다 (`_template.html`).

| 역할 | 글꼴 | 크기 | 굵기 | 행간, 자간 |
|---|---|---|---|---|
| 상단 바 제목 | Space Grotesk | 16px (1rem) | 700 | 1, -0.01em |
| 상단 바 부제 (규모) | Pretendard | 12.5px (0.78rem) | 400 | muted |
| 패널 제목 | Pretendard | 18.4px (1.15rem) | 650 | 1.3, -0.005em |
| 패널 본문, 이웃 목록 | Pretendard | 14px (0.875rem) | 400 | 1.6 / 목록은 1.25 |
| 패널 절 제목 ("이웃 페이지") | Pretendard | 12.5px | 600 | muted. 대문자 변환 금지 |
| 칩, 범례 | JetBrains Mono / Pretendard | 12.5px | 400 | 칩은 mono (사이트 filter-chip 과 같다), 범례 라벨은 Pretendard |
| 수치 (연도, degree, 개수) | JetBrains Mono | 11px (0.6875rem) ~ 12.5px | 400 | `tabular-nums` |

| 노드 | 라벨 크기 | 색 |
|---|---|---|
| degree 50 이상 (허브 5개 내외) | 13px, 굵기 700 | `--graph-label` |
| degree 15 ~ 49 | 12px | `--graph-label` |
| degree 14 이하 | 11px | `--graph-label-muted` |

라벨 뒤에는 `--graph-label-halo` 로 3px stroke를 먼저 그려 엣지 위에서도 읽히게 한다 (`ctx.lineWidth = 3; strokeText` 후 `fillText`). 제목이 28자를 넘으면 27자에서 자르고 `…` 를 붙인다. 툴팁과 패널은 전체 제목을 보인다.

## 3. 카테고리 8색

색은 hue로 카테고리를, 밝기로 degree를 말한다. 아쿠아(agents)와 앰버(physical-ai)는 사이트의 도메인 강조색 그대로이고 나머지 여섯은 그 둘과 겹치지 않는 자리에 놓았다. overviews는 hue 대신 별빛 흰색(라이트에서는 잉크)을 받는다. 다른 페이지를 묶는 허브라 가장 밝은 별로 읽히는 것이 맞다.

| 카테고리 | 노드 수 | 토큰 | dark | light | 모양 |
|---|---|---|---|---|---|
| physical-ai | 149 | `--cat-physical-ai` | `#f0a868` | `#a85b12` | 채운 원 |
| agents | 84 | `--cat-agents` | `#5eead4` | `#0b8a76` | 채운 원 |
| applications | 39 | `--cat-applications` | `#f483ad` | `#c0396f` | 채운 원 |
| database | 28 | `--cat-database` | `#d5bcff` | `#9a5cc8` | 채운 원 |
| llms | 19 | `--cat-llms` | `#6b93ff` | `#2a5fd6` | 채운 원 |
| overviews | 14 | `--cat-overviews` | `#eef1f6` | `#161a22` | 채운 원 + 바깥 고리 |
| evaluations | 6 | `--cat-evaluations` | `#d6e36a` | `#728f00` | 채운 원 |
| etc | 5 | `--cat-etc` | `#6b7484` | `#7a8392` | 빈 원 (1.5px 테) |

검증 결과 (Machado 2009 행렬로 색각 이상 시뮬레이션 후 CIELAB 거리):

- 배경 대비는 dark 4.1 ~ 17.1, light 3.5 ~ 16.4로 모두 그래픽 기준 3:1을 넘는다.
- 가장 가까운 쌍은 light deuteranopia의 physical-ai와 evaluations(ΔE 6.6), light deuteranopia의 agents와 applications(7.4), dark protanopia의 agents와 overviews(10.7)다. 나머지 쌍은 모두 ΔE 12 이상이다.
- llms와 database는 처음 같은 밝기의 파랑, 보라로 잡았다가 protanopia에서 ΔE 1.2로 겹쳐서 밝기를 갈랐다 (dark에서 llms 어둡게, database 밝게).

색만으로 구분하지 않도록 보완 장치를 둔다.

- overviews는 고리, etc는 빈 원으로 모양이 다르다.
- 범례 항목에 호버하거나 누르면 그 카테고리만 남기고 나머지를 `--graph-dim-alpha` 로 낮춘다. 시안은 모두 이 동작을 넣는다.
- 툴팁과 패널은 카테고리 이름을 글자로 적는다.

도메인 2색으로만 보이고 싶은 화면(시안 C의 섬 윤곽 등)은 `--signal`, `--signal-physical` 을 쓴다. 카테고리 색과 도메인 색을 한 요소에 섞지 않는다.

## 4. 노드, 엣지, 라벨

### 노드

- 반지름은 화면 px 기준 `r = 2 + 1.6 * sqrt(degree)`, 상한 20px. degree 1은 3.6px, 25는 10px, 118은 19.4px이다.
- 줌 배율 k에서 그릴 반지름은 `r * k^0.5` 다. 확대해도 허브가 화면을 덮지 않고, 축소해도 잎 노드가 사라지지 않는다.
- dark에서 degree 30 이상 노드는 반지름 `2.6r` 의 원을 카테고리 색, 알파 `--graph-glow-alpha`(0.14)로 먼저 깐다. light는 0이라 글로우가 없다. `shadowBlur` 는 쓰지 않는다 (344개에서 프레임이 떨어진다).
- light에서는 모든 노드에 `--graph-ring` 1px 테를 둘러 겹친 노드를 떼어 보인다.
- 선택 노드는 바깥에 2px 고리(카테고리 색, 반지름 r + 4px)를 더한다. 호버는 고리 1px.

### 엣지

- 기본은 `--graph-edge` 색, 알파 `--graph-edge-alpha`(dark 0.09, light 0.12), 굵기 화면 기준 0.75px. 줌과 무관하게 같은 굵기다.
- 방향 화살표는 기본 화면에 그리지 않는다. 선택 노드의 이웃 엣지에만 끝에 4px 삼각형을 붙인다.
- 선택 또는 호버가 있으면 그 노드의 엣지만 알파 `--graph-edge-hi-alpha`(0.65)로, 색은 상대 노드의 카테고리 색으로 그린다. 나머지 엣지는 알파 0.03까지 낮춘다.
- 2,600개 엣지는 한 번의 `beginPath` 에 모아 `stroke` 한 번으로 그린다. 강조 엣지만 따로 그린다.

### 강조와 흐림

- 선택이나 범례 필터가 있으면 관계없는 노드는 알파 `--graph-dim-alpha`(dark 0.16, light 0.2)로 그린다. 라벨은 숨긴다.
- 1-hop 이웃은 원래 밝기를 유지한다. 2-hop을 보이는 시안(B)은 2-hop을 알파 0.55로 둔다.

### 라벨 드러내기 규칙

줌 배율 k에 따라 라벨을 붙일 degree 하한이 내려간다.

| k | degree 하한 | 대략 라벨 수 |
|---|---|---|
| k < 0.8 | 50 | 5 |
| 0.8 ≤ k < 1.4 | 25 | 25 내외 |
| 1.4 ≤ k < 2.2 | 10 | 화면에 보이는 것만 |
| k ≥ 2.2 | 0 | 화면에 보이는 것만 |

여기에 더해 호버, 선택 노드, 선택 노드의 1-hop 이웃, 검색 일치 노드는 하한과 관계없이 라벨을 붙인다. 라벨끼리 겹치면 degree가 높은 쪽을 남긴다 (사각형 충돌 검사를 degree 내림차순으로 탐욕적으로). 라벨 위치는 노드 중심에서 `(r + 4px, -r)`, 왼쪽 정렬이다. 화면 오른쪽 끝에 걸리면 노드 왼쪽으로 뒤집는다.

## 5. 크롬 컴포넌트

모든 클래스는 `shared/mock-base.css` 에 있다. 시안은 이 클래스를 그대로 쓰고 필요한 변형만 시안 안 `<style>` 에 더한다.

| 요소 | 클래스 | 규격 |
|---|---|---|
| 상단 바 | `.mk-bar` | 높이 48px, 좌우 16px, 유리판 배경 + 하단 hairline |
| 무대 | `.mk-stage` | 바 아래 전체. `touch-action: none` |
| 띄움 위치 | `.mk-float.is-tl` 등 | 무대 가장자리에서 16px |
| 유리판 | `.mk-glass` | surface 82% + blur 12px, hairline, 반경 14px |
| 칩 | `.mk-chip` + `data-cat` | 높이 28px, 좌우 10px, 반경 8px. 눌림은 `aria-pressed="true"` 로 카테고리 색 테두리와 14% 배경 |
| 견본 점 | `.mk-swatch` | 8px 원. `data-cat` 하나로 칩, 범례, 패널, 툴팁 색이 맞는다 |
| 검색 | `.mk-search` | 입력 높이 36px, 폭 320px (모바일 100%). 결과는 `.mk-results`, 최대 높이 320px, 활성 항목 `aria-selected` |
| 상세 패널 | `.mk-panel` | 우측 폭 360px, 상하 16px 띄움. 모바일(≤640px)은 하단 시트, 최대 60vh |
| 범례 | `.mk-legend` | 좌하단. 항목 높이 22px, 개수는 mono 11px 우측 정렬 |
| 툴팁 | `.mk-tip` | 최대 폭 280px, 포인터에서 (12px, 12px) 떨어뜨림. 화면 밖이면 반대편으로 |
| 버튼 | `.mk-btn`, `.mk-btn.is-primary` | 높이 36px. 페이지 이동은 primary 하나만 |

반경은 위계를 따른다. 떠 있는 판(패널, 범례)은 14px, 누르는 것(칩, 버튼, 입력)은 8px, 태그와 포커스 링은 4px이다. 그림자는 패널, 검색 결과, 툴팁처럼 다른 것 위에 뜨는 세 가지에만 둔다.

문구는 하는 일을 적는다. "페이지 열기", "선택 해제", "이웃 페이지", "페이지 제목으로 찾기". 빈 검색 결과는 "일치하는 페이지가 없다. 영문 제목으로 찾아 본다" 처럼 다음 행동을 적는다.

## 6. 여백과 배치

- 4px 격자. 컴포넌트 안쪽은 8 / 12 / 16px, 컴포넌트 사이는 8px, 무대 가장자리는 16px이다.
- 캔버스 그래프의 바깥 여백은 무대 짧은 변의 6%다. 처음 맞춤(fit) 때 이 여백을 남긴다. 패널이 열려 있으면 패널 폭 + 32px만큼 오른쪽을 비우고 맞춘다.
- 정렬은 왼쪽이다. 가운데 정렬은 캔버스 위 빈 상태 문구 하나뿐이다.
- 375px 폭: 상단 바는 제목과 토글만 남기고 부제를 숨긴다. 검색은 상단 전폭, 범례는 접어서 견본 점 8개 한 줄로 둔다. 가로 스크롤이 생기면 안 된다.

## 7. 모션

| 상황 | 시간 | easing | 토큰 |
|---|---|---|---|
| 호버 색, 테두리 | 120ms | `--ease` | `--dur-fast` |
| 테마 전환 배경 | 180ms | `--ease` | `--dur` |
| 패널 열고 닫기 | 240ms | `--ease-out` `cubic-bezier(0.22, 1, 0.36, 1)` | `--dur-panel` |
| 카메라 이동 (검색 결과, 이웃 클릭, 맞춤) | 480ms | `--ease-out` | `--dur-camera` |
| 첫 등장 | 600ms | `--ease-out` | `--dur-reveal` |
| 강조 흐림 전환 (캔버스) | 160ms | 선형 보간 | 시안 코드 |

- 첫 등장은 한 번만 연출한다. force 배치는 화면에 그리기 전에 미리 계산해 두고(동기 tick 300회 정도), 노드가 degree 내림차순으로 600ms에 걸쳐 나타난 뒤 엣지가 페이드인한다. 배치가 화면에서 흔들리며 자리 잡는 장면은 보이지 않는다.
- 그 뒤로 저절로 움직이는 것은 없다. 허브의 숨쉬는 글로우나 떠다니는 노드는 넣지 않는다.
- 노드 드래그는 놓으면 그 자리에 고정한다 (시뮬레이션 재가열 없음). 시안 A처럼 재배치가 필요하면 알파 0.3에서 짧게 식힌다.
- `prefers-reduced-motion: reduce` 에서는 첫 등장, 카메라 이동, 강조 전환을 모두 즉시 바꾼다. 패널은 슬라이드 없이 나타난다. CSS 전환은 `mock-base.css` 가 0ms로 막고, 캔버스 쪽은 `Mock.reduceMotion()` 으로 시안이 직접 건너뛴다. 3D 시안(E)은 자동 회전을 끄고 정지 상태로 연다.

## 8. 라이트와 다크

| 항목 | dark | light |
|---|---|---|
| 무대 배경 | `#0b0e14` | `#f7f8fa` |
| 엣지 | `#8a93a3` 알파 0.09 | `#5c6473` 알파 0.12 |
| 노드 글로우 | degree 30 이상, 알파 0.14 | 없음 |
| 노드 테 | 없음 | `#f7f8fa` 1px |
| 라벨 후광 | `rgba(11,14,20,0.85)` | `rgba(247,248,250,0.9)` |
| overviews 색 | 별빛 `#eef1f6` | 잉크 `#161a22` |
| 떠 있는 판 그림자 | `0 12px 32px rgba(0,0,0,0.45)` | `0 12px 32px rgba(22,26,34,0.12)` |

다크가 기본 화면이고 성도의 인상도 다크에서 나온다. 라이트는 같은 그림을 종이 위 인쇄처럼 보이게 한다. 글로우를 빼고 테를 더해 밀도를 잉크로 표현한다.

테마 전환은 `<html data-theme>` 를 바꾸고, 캔버스는 `Mock.onTheme(cb)` 로 받은 새 토큰으로 다시 그린다. 캔버스 안에 색 hex를 하드코딩하지 않는다.

## 9. 데이터

`shared/graph-data.js` 는 `window.GRAPH_DATA = { generated, nodes, edges }` 다. 노드 필드는 `id`, `stem`, `title`, `category`, `domain`, `degree`, `year`, `type`, `tags` 이고 엣지는 `{ source, target }` (id 문자열)이다. 다시 만들려면 저장소 루트에서 `node docs/graph-mockups/build-data.mjs` 를 돌린다.

연도는 344개 전부 있지만 2026년이 256개(74%), 2025년이 51개다. 연도축 시안(D)은 2026년 한 칸에 노드가 몰리는 것을 전제로 그 칸 안의 배치를 따로 설계해야 한다.
